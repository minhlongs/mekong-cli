Developer Telemetry FAQ

Key implementation questions on local sandboxing, MCU micro-transactions, and TT78 taxation compliance.

01 //

What exactly is an MCU (Mekong Compute Unit)?

MCU is an exact measurement unit for offloaded deterministic ledger operations, PayOS webhook state verification, and TT78 RSA-SHA256 signature calculations. All local LLM inference and SQLite queries running on your bare-metal Apple Silicon or Linux hardware burn zero MCU.

02 //

Can I run Mekong completely offline without internet?

Yes. The Community and Enterprise tiers support air-gapped sovereign environments. Agents process data locally inside memory-mapped SQLite and write Merkle append-only logs. When an internet connection is re-established, the platform synchronizes PayOS receipts if configured.

03 //

How does VietQR PayOS automated replenishment work?

When your agent swarm detects credits falling below 500 MCU, your configured PayOS webhook endpoint generates an instant VietQR code with a unique cryptographic memo. Once scanned via any Vietnamese banking app (VCB, TPBank, MB, etc.), PayOS triggers an AES-256 signed ping that unlocks new compute credits in under 3 seconds.

04 //

Is TT78 invoice validation legal and compliant in Vietnam?

Fully compliant. Mekong embeds the official XML schema and RSA-SHA256 digital certificate validation logic designated by the Vietnamese General Department of Taxation (Tong Cuc Thue - Circular 78/2021/TT-BTC). All invoice audits generate legally admissible cryptographic proof hashes.
