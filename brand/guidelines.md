# OpenClaw RaaS Gateway — Brand Guidelines

> Brand System version: 1.0.0
> Date: 2026-05-28
> Status: Active

Consistent branding builds trust and makes the sovereign agent stack recognizable. This document outlines the core visual identity guidelines for the OpenClaw RaaS Gateway project.

---

## 1. Brand Mission & Values

*   **Speed**: Sub-millisecond execution start times (Edge-first via Cloudflare Workers).
*   **Security**: Sovereign LLM execution, zero-knowledge keys, and robust permission boundaries.
*   **Adaptability**: Seamless multi-layer Water Protocol (Studio → Founder → Business → Product → Engineering → Ops) connecting agents dynamically.

## 3. Typography Scale

*   **Headings Font**: `Outfit, sans-serif` (Vibrant, geometric, modern)
*   **Body Font**: `Inter, sans-serif` (Highly legible, crisp, professional)
*   **Monospace Font**: `Fira Code, monospace` (For console logs, parameters, contracts, terminal UI)

### Typesetting Hierarchy
- **Title (H1)**: `2.5rem / 40px`, Line Height `1.2`, Bold, Letter Spacing `-0.02em`
- **Section Heading (H2)**: `2.0rem / 32px`, Line Height `1.25`, Semibold, Letter Spacing `-0.015em`
- **Sub-heading (H3)**: `1.5rem / 24px`, Line Height `1.3`, Semibold
- **Body Text**: `1.0rem / 16px`, Line Height `1.5`, Regular
- **Telemetry Labels (Caption)**: `0.75rem / 12px`, Line Height `1.4`, Medium, All Caps, Letter Spacing `0.05em`

## 5. UI Spacing & Grid System

All layouts must follow the **4dp/8dp spacing rhythm** to maintain visual balance:

- **4px / 8px**: Micro-adjustments, button padding, gap between labels and inputs.
- **16px**: Body padding, item list spacing, standard gutter.
- **24px / 32px**: Page container margin, card padding, section gap.
- **64px / 96px**: Large landing page vertical section spacing.
