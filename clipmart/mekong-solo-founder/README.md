# Mekong Solo Founder

> Lean AI company template — 5 essential agents for solo founders.

A minimal subset of the full [mekong-saas-startup](../mekong-saas-startup) template,
optimized for solo founders who need to **ship fast** without managing 22 departments.

---

## The 5 Agents

| Agent | Role | Team | Budget |
|-------|------|------|--------|
| **ceo** | Chief Executive Officer | executive | 500 MCU/mo |
| **engineer** | Lead Engineer | engineering | 400 MCU/mo |
| **marketer** | Head of Marketing | revenue | 300 MCU/mo |
| **cfo** | Chief Financial Officer | operations | 200 MCU/mo |
| **legal** | Legal Counsel | operations | 150 MCU/mo |

Total monthly budget: **1,550 MCU/mo**

---

## Agent Coverage

```
Strategy & Vision   →  ceo        (始計 — Laying Plans)
Build & Ship        →  engineer   (軍爭 — Military Contention)
Grow & Acquire      →  marketer   (兵勢 — Momentum)
Money & Runway      →  cfo        (作戰 — Waging War)
Risk & Compliance   →  legal      (行軍 — Army on March)
```

## Quick Start

```bash
# Install via Paperclip CLI
npx paperclipai company import mekong-solo-founder

# Or clone manually
git clone https://github.com/longtho638-jpg/mekong-cli
cd mekong-cli/clipmart/mekong-solo-founder
npx paperclipai company init .

# Launch your company
mekong company/start
```

## Binh Pháp Governance

Each agent is governed by a chapter of 孫子兵法 (Sun Tzu's Art of War):

| Agent | Chapter | Principle |
|-------|---------|-----------|
| ceo | 始計 | Initial Calculations — plan before acting |
| engineer | 軍爭 — Contending for Advantage | Speed + precision in execution |
| marketer | 兵勢 — Momentum | Build unstoppable growth |
| cfo | 作戰 — Waging War | Manage resources, extend runway |
| legal | 行軍 — Army on March | Navigate terrain, avoid traps |
