# Outcome-Based Pricing Rationale — Frontend Engineering Department

## Market Reference Points

| Vendor | What They Charge | Annual Cost |
|--------|-----------------|-------------|
| Frontend Engineer (senior) | $130,000-170,000/yr | $150,000/yr avg |
| Design-to-code tools (v0.dev) | $20/mo | $240/yr |
| Figma | $45/editor/mo | $540/yr |
| Storybook Pro | $50/mo | $600/yr |
| Agency frontend rate | $100-200/hr | $208,000/yr (FT equiv) |

## Our Pricing Model

```
Base: $49/mo (200 credits)
UI component from Figma: $12
Responsive fix: $8
Full page implementation: $20
```

**Savings:** $12 per component vs. agency $100-200/hr for same component (1-3 hours = $100-600).
