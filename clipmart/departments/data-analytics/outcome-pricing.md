# Outcome-Based Pricing Rationale — Data Analytics Department

## Market Reference Points

| Vendor | What They Charge | Annual Cost |
|--------|-----------------|-------------|
| Data Engineer salary | $140,000-180,000/yr | $160,000/yr avg |
| dbt Cloud | $100-500/mo | $1,200-6,000/yr |
| Fivetran | $500-2,000/mo | $6,000-24,000/yr |
| Snowflake | $400-2,000/mo | $4,800-24,000/yr |
| Looker | $3,000-5,000/mo | $36,000-60,000/yr |

## Our Pricing Model

```
Base: $49/mo (200 credits)
Pipeline built + tested: $30
Daily pipeline run: $5
Data quality audit: $20
Metric dashboard: $25
```

**Savings vs. data engineer:** $160,000/yr → ~$3,600/yr for equivalent deliverables.
