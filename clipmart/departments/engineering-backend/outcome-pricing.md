# Outcome-Based Pricing Rationale — Backend Engineering Department

## Market Reference Points

| Vendor | What They Charge | Annual Cost |
|--------|-----------------|-------------|
| Backend Engineer (senior) | $140,000-180,000/yr | $160,000/yr avg |
| GitHub Copilot Enterprise | $39/user/mo | $4,680/yr |
| Cursor AI | $40/user/mo | $480/yr |
| Code review tool (Reviewpad) | $6/user/mo | $720/yr |
| Agency dev rate | $150-300/hr | $312,000/yr (FT equiv) |

## Our Pricing Model

```
Base: $49/mo (200 credits)
API endpoint built + tested: $15
Database migration: $10
Feature complete: $25
Code review (PR): $8
```

**Savings vs. engineer:** $160,000/yr vs. $15 per API endpoint. At 1 endpoint/day = $450/month vs $13,333/month.
