# Outcome-Based Pricing Rationale — IT Security Department

## Market Reference Points

| Vendor | What They Charge | Annual Cost |
|--------|-----------------|-------------|
| IT Security Engineer | $120,000-160,000/yr | $140,000/yr avg |
| CrowdStrike Falcon | $8-15/endpoint/mo | $9,600-18,000/yr (100 devices) |
| Okta (identity) | $4-8/user/mo | $4,800-9,600/yr (100 users) |
| Snyk | $98-198/dev/mo | $11,760-23,760/yr (10 devs) |
| Qualys VMDR | $500-2,000/mo | $6,000-24,000/yr |

## Our Pricing Model

```
Base: $49/mo (200 credits)
Security scan + report: $20
Endpoint compliance check: $8
IT service ticket: $5
IT inventory audit: $15
```

**Savings vs. IT security engineer + tools:** $166,800/yr → ~$2,400/yr.
