# /auction — Auction — Vietnamese Property Auction, Distressed Asset Liquidation & Judicial Asset Disposal Suite

Auction — Vietnamese Property Auction, Distressed Asset Liquidation & Judicial Asset Disposal Suite.

## Usage

```bash
// turbo
mekong auction $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `auctioneer` | Đăng ký và thẩm tra hồ sơ hành nghề Đấu giá viên theo Điều 10, 14 Luật Đấu giá tài sản. |
| `asset` | Niêm yết và thẩm tra quy chế tài sản đấu giá theo Điều 35, 39 Luật Đấu giá tài sản. |
| `bidder` | Đăng ký tham gia đấu giá và thẩm tra nộp tiền đặt trước theo Điều 38, 39 Luật ĐGTS. |
| `session` | Tổ chức cuộc đấu giá, công nhận kết quả trúng đấu giá và lập Biên bản theo Điều 44. |
| `audit` | Thẩm tra rủi ro thông đồng, dìm giá hoặc dàn xếp bỏ cọc theo Điều 9 Luật ĐGTS & Điều 218 BLHS. |
| `list` | Tra cứu danh mục đấu giá viên, tài sản niêm yết, người đăng ký và biên bản phiên đấu giá. |
| `status` | Hiển thị tổng quan các chỉ số telemetry hoạt động đấu giá tài sản toàn quốc. |
