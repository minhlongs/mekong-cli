# /payroll — Payroll — Vietnamese statutory payroll, Gross-to-Net & compensation engine

Payroll — Vietnamese statutory payroll, Gross-to-Net & compensation engine.

## Usage

```bash
// turbo
mekong payroll $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `gross-to-net` | Tính toán chi tiết từ lương Gross sang Net, bảo hiểm và thuế TNCN. |
| `net-to-gross` | Quy đổi từ lương Net sang mức lương Gross hợp đồng tương đương. |
| `payslip` | Lập và lưu trữ phiếu lương điện tử cho nhân viên. |
| `list` | Tra cứu danh sách phiếu lương điện tử đã lập. |
| `status` | Kiểm tra thông số cấu hình và tổng hợp dữ liệu quỹ lương. |
