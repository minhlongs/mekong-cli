# /governance — ZenOS Commons governance: propose, vote, tally, and inspect proposals

ZenOS Commons governance: propose, vote, tally, and inspect proposals.

## Usage

```bash
// turbo
mekong governance $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `propose` | Draft + submit a new constitutional amendment proposal. |
| `vote` | Start voting on a proposal and record a single vote. |
| `tally` | Tally votes and finalize a proposal. |
| `list` | List all Commons governance proposals. |
