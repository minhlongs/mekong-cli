# /citizenship — Citizenship — Alias for Vietnamese Nationality & Citizenship Rights Suite (Luật Quốc tịch Việt Nam 2008/2014)

Citizenship — Alias for Vietnamese Nationality & Citizenship Rights Suite (Luật Quốc tịch Việt Nam 2008/2014).

## Usage

```bash
// turbo
mekong citizenship $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `naturalize` | Process and evaluate Naturalization in Vietnam under Article 19. |
| `renounce` | Process and evaluate Renunciation of Vietnamese Nationality under Article 27. |
| `restore` | Process Restoration of Vietnamese Nationality under Article 23. |
| `certificate` | Issue or register Certificate of Vietnamese Nationality under Decree 16/2020/ND-CP. |
| `list` | List nationality affairs records by category. |
| `status` | Show Vietnamese nationality affairs telemetry and system status. |
