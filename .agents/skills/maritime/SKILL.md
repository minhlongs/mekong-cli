# /maritime — Maritime — Vietnamese Maritime Code 2015, seaport terminal operations, ICD & customs e-Manifest

Maritime — Vietnamese Maritime Code 2015, seaport terminal operations, ICD & customs e-Manifest.

## Usage

```bash
// turbo
mekong maritime $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `vessel` | Đăng ký lịch trình cập cầu và điều độ tàu biển thương mại (Nghị định 58/2017/NĐ-CP). |
| `container` | Quản trị xếp dỡ vị trí bãi bến và kho hàng cảng cạn ICD (Nghị định 38/2017/NĐ-CP & SOLAS VGM). |
| `tariff` | Tính toán biểu cước phí cầu bến, hoa tiêu và bốc dỡ container (Thông tư 39/2023/TT-BGTVT). |
| `manifest` | Khai báo bản lược khai hàng hóa điện tử (e-Manifest) qua Cổng thông tin Một cửa Quốc gia / VNACCS. |
| `list` | Truy vấn danh mục lịch trình tàu cập cảng hoặc container lưu giữ bãi bến/ICD. |
| `status` | Truy vấn trạng thái hoạt động và số liệu thống kê luồng hàng hải. |
