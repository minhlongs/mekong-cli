# /statebudget — State Budget — Vietnamese State Budget, Fiscal Discipline, Public Treasury Accounts & Budget Allocations Suite

State Budget — Vietnamese State Budget, Fiscal Discipline, Public Treasury Accounts & Budget Allocations Suite.

## Usage

```bash
// turbo
mekong statebudget $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `estimate` | Lập và phê duyệt dự toán ngân sách nhà nước theo Luật Ngân sách nhà nước 2015 (Điều 28-50). |
| `commit` | Đăng ký cam kết chi ngân sách nhà nước qua Kho bạc Nhà nước theo Thông tư 342/2016/TT-BTC. |
| `payout` | Thực hiện xuất chi ngân sách qua Kho bạc Nhà nước theo Luật Ngân sách nhà nước 2015 (Điều 51-62). |
| `audit` | Ghi nhận kết luận kiểm tra, kiểm toán kỷ luật tài khóa ngân sách nhà nước theo Điều 18 & 70-73. |
| `list` | Liệt kê danh sách dự toán ngân sách, cam kết chi, chứng từ giải ngân và kết luận kiểm toán. |
| `status` | Báo cáo chỉ số telemetry, tốc độ chấp hành và kỷ luật ngân sách nhà nước toàn quốc. |
