# /stitch-design-system — Cyber-Bento Horizon Design System

Enforces consistent design tokens across all Stitch prompts, CSS files, and component architectures.

## Core Tokens
- **Canvas**: Obsidian Deep Space `#090A0F`
- **Panels**: Slate `#11131A`, Hover `#181B26`
- **Borders**: Subtle `#1E2230`, Active `#2D3748`
- **Signals**: Cyber Emerald `#10B981`, Cyan `#06B6D4`, Amber `#F59E0B`, Crimson `#EF4444`
- **Radii**: Cards `12px`, Buttons `8px`, Pills `9999px`
- **Typography**: Space Grotesk / Inter / JetBrains Mono

## Section 6 Prompt Injection Block
Every Stitch generation prompt must include the verbatim Section 6 block from `DESIGN.md`.
