# /securedtransactions — SecuredTransactions — Vietnamese Registration of Security Interests & Secured Transactions Suite (Nghị định 99/2022)

SecuredTransactions — Vietnamese Registration of Security Interests & Secured Transactions Suite (Nghị định 99/2022).

## Usage

```bash
// turbo
mekong securedtransactions $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `register` | Register initial or modified security measure under Civil Code 2015 and Decree 99/2022. |
| `collateral` | Record collateral asset and link to security registration. |
| `priority` | Calculate statutory repayment priority ranking over an asset under Article 308 Civil Code 2015. |
| `disposal` | Register formal notice of collateral disposal under Article 51 Decree 99/2022. |
| `deregister` | Release and cancel security interest registration upon obligation termination under Article 52 Decree 99/2022. |
| `search` | Search registered security measures across National Registry database. |
| `list` | List secured transactions records by category. |
| `status` | Show national secured transactions registry statistics. |
