# /bankruptcy — Bankruptcy — Vietnamese Corporate Insolvency, Bankruptcy, Debt Restructuring & Asset Liquidation Suite

Bankruptcy — Vietnamese Corporate Insolvency, Bankruptcy, Debt Restructuring & Asset Liquidation Suite.

## Usage

```bash
// turbo
mekong bankruptcy $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `practitioner` | Đăng ký và thẩm tra tư cách hành nghề Quản tài viên theo Điều 12 Luật Phá sản & NĐ 22/2015/NĐ-CP. |
| `petition` | Nộp và thẩm tra Đơn yêu cầu mở thủ tục phá sản theo Điều 5, Điều 40-42 Luật Phá sản. |
| `claim` | Đăng ký Giấy đòi nợ và lập Danh sách chủ nợ theo Điều 64-67 Luật Phá sản. |
| `meeting` | Tổ chức Hội nghị chủ nợ và thông qua Nghị quyết theo Điều 75-86 Luật Phá sản. |
| `distribute` | Tính toán phân chia tài sản thanh lý theo thứ tự ưu tiên Điều 54 Luật Phá sản 2014. |
| `list` | Tra cứu danh mục Quản tài viên, đơn yêu cầu, danh sách chủ nợ và bảng phân chia tài sản. |
| `status` | Hiển thị tổng quan các chỉ số telemetry hoạt động giải quyết phá sản doanh nghiệp toàn quốc. |
