# /ip — IP — Intellectual Property, Trademarks, Patents & Software Copyright

IP — Intellectual Property, Trademarks, Patents & Software Copyright.

## Usage

```bash
// turbo
mekong ip $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `trademark` | Nộp đơn đăng ký bảo hộ nhãn hiệu theo Thỏa ước Nice & Luật SHTT 2022. |
| `search` | Tra cứu xung đột và đánh giá khả năng gây nhầm lẫn của nhãn hiệu (Điều 74 Luật SHTT). |
| `patent` | Soạn thảo bản mô tả sáng chế và các điểm yêu cầu bảo hộ (Claims) theo Điều 102 Luật SHTT. |
| `copyright` | Thiết lập hồ sơ đăng ký bản quyền tác phẩm phần mềm máy tính (Nghị định 17/2023/NĐ-CP). |
| `fees` | Tính toán chi tiết lệ phí nhà nước bảo hộ SHTT theo Thông tư 263/2016/TT-BTC. |
| `list` | Truy vấn danh mục tài sản sở hữu trí tuệ đã đăng ký trong hệ thống. |
| `status` | Tra cứu trạng thái cơ sở dữ liệu sở hữu trí tuệ và phân loại Nice. |
