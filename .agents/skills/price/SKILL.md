# /price — Price — Vietnamese Price Management, Anti-Price Gouging & Valuation Suite

Price — Vietnamese Price Management, Anti-Price Gouging & Valuation Suite.

## Usage

```bash
// turbo
mekong price $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `declare` | Kê khai giá hàng hóa, dịch vụ theo Điều 28 Luật Giá 2023 và kiểm tra biên độ tăng giá. |
| `posting` | Hậu kiểm tuân thủ quy định niêm yết giá theo Điều 29 Luật Giá 2023 và xử phạt bán sai giá niêm yết. |
| `valuation` | Ban hành và thẩm tra Chứng thư Thẩm định giá theo Chuẩn mực Thẩm định giá Việt Nam (TĐGVN). |
| `gouge` | Kiểm tra và xử lý hành vi đầu cơ găm hàng, tăng giá bất hợp lý trong thiên tai dịch bệnh. |
| `list` | Tra cứu danh mục hồ sơ kê khai giá, niêm yết giá, chứng thư thẩm định hoặc xử lý tăng giá. |
| `status` | Báo cáo chỉ số telemetry tổng hợp quản lý giá, bình ổn giá và thẩm định giá. |
