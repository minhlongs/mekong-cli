# /audit — Audit — Enterprise SOX 404, ITGC & COSO internal controls audit engine

Audit — Enterprise SOX 404, ITGC & COSO internal controls audit engine.

## Usage

```bash
// turbo
mekong audit $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `run` | Thực thi quy trình kiểm toán tự động các chốt kiểm soát nội bộ (SOX 404 / ITGC). |
| `controls` | Tra cứu ma trận các chốt kiểm soát nội bộ và thủ tục kiểm tra. |
| `findings` | Xem danh sách các phát hiện kiểm toán, khiếm khuyết nội bộ và phương án khắc phục. |
| `status` | Kiểm tra tổng quan vị thế kiểm toán và tỷ lệ tuân thủ nội bộ. |
