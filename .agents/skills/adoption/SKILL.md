# /adoption — Adoption — Vietnamese Child Adoption & Hague Intercountry Adoption Suite (Luật Nuôi con nuôi 2010)

Adoption — Vietnamese Child Adoption & Hague Intercountry Adoption Suite (Luật Nuôi con nuôi 2010).

## Usage

```bash
// turbo
mekong adoption $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `apply` | Register and validate child adoption application under Law on Adoption 2010. |
| `intercountry` | Process Hague Convention intercountry child adoption dossier. |
| `report` | Submit post-placement welfare and development report (semi-annual for 3 years). |
| `certificate` | Issue official Certificate of Adoption (Giấy chứng nhận nuôi con nuôi). |
| `terminate` | Enforce judicial termination of adoption relationship under Article 25. |
| `list` | List child adoption records by category. |
| `status` | Show Vietnamese child adoption and Hague Convention telemetry. |
