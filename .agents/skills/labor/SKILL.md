# /labor — Labor — Vietnamese Labor Code 2019, foreign work permits, overtime caps & safety compliance

Labor — Vietnamese Labor Code 2019, foreign work permits, overtime caps & safety compliance.

## Usage

```bash
// turbo
mekong labor $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `permit` | Thẩm định điều kiện cấp Giấy phép lao động (GPLĐ) hoặc Xác nhận Miễn GPLĐ (Nghị định 70/2023/NĐ-CP). |
| `overtime` | Tính toán tiền lương làm thêm giờ và làm việc ban đêm chuẩn xác theo Điều 98 Bộ luật Lao động 2019. |
| `caps` | Kiểm tra giới hạn trần làm thêm giờ theo tháng (<= 40h) và theo năm (<= 200h hoặc 300h) - Điều 107 BLLĐ. |
| `severance` | Tính toán trợ cấp thôi việc (Điều 46) hoặc trợ cấp mất việc làm (Điều 47) khi chấm dứt HĐLĐ. |
| `regulations` | Rà soát tính hợp pháp của Nội quy lao động và nghĩa vụ đăng ký Sở LĐ-TB&XH (Điều 118 & 119 BLLĐ). |
| `list` | Liệt kê danh sách lao động nước ngoài hoặc hồ sơ đề nghị cấp Giấy phép lao động. |
| `status` | Truy vấn telemetry hệ thống pháp luật lao động, hồ sơ GPLĐ và tuân thủ NQLĐ. |
