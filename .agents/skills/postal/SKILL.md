# /postal — Postal — Vietnamese Postal, Express Delivery & Courier Logistics

Postal — Vietnamese Postal, Express Delivery & Courier Logistics.

## Usage

```bash
// turbo
mekong postal $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `license` | Thẩm tra điều kiện và cấp Giấy phép kinh doanh dịch vụ bưu chính theo Luật Bưu chính 2010. |
| `waybill` | Tạo vận đơn bưu gửi EMS, tính trọng lượng quy đổi thể tích và biểu cước trọn gói. |
| `sla` | Thẩm tra thời gian toàn trình chuyển phát bưu gửi theo tiêu chuẩn QCVN 01:2018/BTTTT. |
| `security` | Soi chiếu an ninh bưu phẩm, phát hiện và xử lý vật phẩm cấm gửi theo Luật Bưu chính. |
| `indemnity` | Xác định trách nhiệm bồi thường thiệt hại mất mát, hư hỏng hoặc phát chậm theo NĐ 47/2011/NĐ-CP. |
| `list` | Tra cứu dữ liệu giấy phép, vận đơn, hồ sơ SLA, soi chiếu an ninh, bồi thường. |
| `status` | Tra cứu trạng thái telemetry tổng thể của mạng lưới bưu chính và chuyển phát nhanh. |
