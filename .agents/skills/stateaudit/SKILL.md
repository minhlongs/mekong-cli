# /stateaudit — State Audit — Vietnamese State Audit, Supreme Audit Institution (SAV / KTNN) & Public Financial Oversight Suite (Luật Kiểm toán nhà nước 2015)

State Audit — Vietnamese State Audit, Supreme Audit Institution (SAV / KTNN) & Public Financial Oversight Suite (Luật Kiểm toán nhà nước 2015).

## Usage

```bash
// turbo
mekong stateaudit $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `engagement` | Register a formal State Audit mission pursuant to Decision by the State Auditor General. |
| `finding` | Record an identified compliance defect, budget leak, or 3E inefficiency in State Audit logs. |
| `recommend` | Issue a formal State Audit Recommendation under Articles 37 & 48 of Law 81/2015/QH13. |
| `settle` | Record execution / financial remediation by audited entity. |
| `conclude` | Conclude or officially publish the final audit report. |
| `list` | List state audit engagements, findings, recommendations, and settlements. |
| `status` | Get aggregate telemetry metrics on state audit engagements and fiscal recoveries. |
