# /defense — Defense — Vietnamese National Defense Industry, Security Export Controls & Industrial Mobilization Suite

Defense — Vietnamese National Defense Industry, Security Export Controls & Industrial Mobilization Suite.

## Usage

```bash
// turbo
mekong defense $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `license` | Thẩm tra điều kiện cấp Giấy phép sản xuất CNQP và an ninh theo Điều 19-21 Luật 38/2024/QH15. |
| `dual-use` | Kiểm soát xuất nhập khẩu hàng hóa, công nghệ lưỡng dụng và kiểm tra EUC theo Điều 28-30. |
| `mobilization` | Thẩm định phương án chuẩn bị động viên công nghiệp phục vụ quốc phòng theo Điều 45-50. |
| `qa` | Nghiệm thu tiêu chuẩn kỹ thuật quân sự TCVN/QS và độ bền tác chiến theo Điều 25. |
| `list` | Tra cứu danh mục giấy phép CNQP, kiểm soát lưỡng dụng, động viên và nghiệm thu khí tài. |
| `status` | Báo cáo chỉ số telemetry tổng hợp công nghiệp quốc phòng và động viên công nghiệp quốc gia. |
