# /marketplace — Plugin marketplace for discovering and installing extensions

Plugin marketplace for discovering and installing extensions.

## Usage

```bash
// turbo
mekong marketplace $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `list` | List all loaded plugins available in the marketplace. |
