# /livestock — Livestock — Vietnamese Animal Husbandry, Livestock Farming, Feed Standards & Biosecurity

Livestock — Vietnamese Animal Husbandry, Livestock Farming, Feed Standards & Biosecurity.

## Usage

```bash
// turbo
mekong livestock $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `farm` | Đăng ký trang trại chăn nuôi, tính Đơn vị vật nuôi (ĐVN), quy mô và mật độ chăn nuôi. |
| `distance` | Đánh giá khoảng cách an toàn sinh học trang trại chăn nuôi theo Điều 5 Nghị định 13/2020/NĐ-CP. |
| `feed` | Kiểm định chất lượng thức ăn chăn nuôi theo QCVN 01-183:2016/BNNPTNT & Thông tư 21/2019/TT-BNNPTNT. |
| `waste` | Thẩm định công trình xử lý chất thải và dung tích hầm Biogas theo Nghị định 46/2022/NĐ-CP. |
| `list` | Tra cứu danh sách trang trại chăn nuôi, an toàn sinh học, kiểm định thức ăn hoặc biogas. |
| `status` | Báo cáo tổng quan hệ thống trang trại chăn nuôi, an toàn sinh học, thức ăn và biogas. |
