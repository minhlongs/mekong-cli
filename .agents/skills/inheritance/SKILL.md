# /inheritance — Inheritance — Vietnamese Inheritance, Wills, Estate Administration & Succession Regimes Suite (BLDS 2015)

Inheritance — Vietnamese Inheritance, Wills, Estate Administration & Succession Regimes Suite (BLDS 2015).

## Usage

```bash
// turbo
mekong inheritance $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `estate-create` | Mở hồ sơ quản lý di sản thừa kế (Articles 609, 611, 612 BLDS 2015). |
| `asset-add` | Thêm tài sản vào danh mục kiểm kê di sản thừa kế (Điều 612 BLDS 2015). |
| `obligation-add` | Ghi nhận nghĩa vụ tài sản và nợ của người chết theo thứ tự ưu tiên (Điều 615 & 658 BLDS 2015). |
| `will-register` | Đăng ký & thẩm định tính hợp pháp của Di chúc (Articles 624-648 BLDS 2015). |
| `heir-add` | Thêm người thừa kế theo luật hoặc di chúc (Articles 644, 651, 652, 653 BLDS 2015). |
| `disclaim` | Ghi nhận văn bản từ chối nhận di sản thừa kế (Điều 620 BLDS 2015 & Điều 59 Luật Công chứng). |
| `calculate` | Tính toán phân chia di sản thừa kế theo luật, di chúc & suất bắt buộc Điều 644. |
| `divide` | Lập Văn bản thỏa thuận phân chia di sản / Khai nhận di sản & kiểm tra niêm yết 15 ngày (Điều 57, 58 Luật Công chứng). |
| `statute-check` | Kiểm tra thời hiệu thừa kế 30 năm (BĐS), 10 năm (động sản), 03 năm (nghĩa vụ nợ) (Điều 623 BLDS 2015). |
| `dossier` | Xuất trọn bộ Hồ sơ Pháp lý thừa kế phục vụ Công chứng, Sang tên Sổ đỏ & Ngân hàng. |
| `audit` | Thẩm định tuân thủ pháp luật thừa kế toàn diện (Civil Code 2015 Compliance Audit). |
| `show` | Xem chi tiết hồ sơ di sản thừa kế. |
| `list` | Danh sách các hồ sơ di sản thừa kế. |
