# /securities — Securities — Vietnamese Securities, Stock Exchanges & Capital Markets

Securities — Vietnamese Securities, Stock Exchanges & Capital Markets.

## Usage

```bash
// turbo
mekong securities $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `offering` | Thẩm định điều kiện chào bán cổ phiếu ra công chúng hoặc IPO theo Luật Chứng khoán 2019. |
| `listing` | Thẩm tra tiêu chuẩn niêm yết cổ phiếu trên HOSE, HNX hoặc UPCoM theo Nghị định 155/2020/NĐ-CP. |
| `margin` | Giám sát tỷ lệ ký quỹ tài khoản, phát hiện Margin Call hoặc Force Sell (Thông tư 120/2020/TT-BTC). |
| `safety` | Thẩm tra Tỷ lệ an toàn tài chính (CAR) của công ty chứng khoán theo Thông tư 121/2020/TT-BTC. |
| `license` | Cấp Chứng chỉ hành nghề chứng khoán chuyên nghiệp theo Luật Chứng khoán 2019. |
| `list` | Tra cứu danh mục hồ sơ chào bán, cổ phiếu niêm yết, tài khoản margin, an toàn vốn hoặc CCHN. |
| `status` | Kiểm tra tình trạng toàn diện thị trường chứng khoán và quản trị rủi ro. |
