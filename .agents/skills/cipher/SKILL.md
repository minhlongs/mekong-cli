# /cipher — Cipher — Vietnamese National Cryptography, State Cipher & Civil Cryptography Suite (Luật Cơ yếu 2011 & Nghị định 58/2016/NĐ-CP)

Cipher — Vietnamese National Cryptography, State Cipher & Civil Cryptography Suite (Luật Cơ yếu 2011 & Nghị định 58/2016/NĐ-CP).

## Usage

```bash
// turbo
mekong cipher $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `system` | Register a state cryptographic system protecting state secrets (Article 11 Law 05/2011/QH13). |
| `key` | Issue and record a cryptographic key lifecycle record (Article 15 Law 05/2011/QH13). |
| `license` | Issue or register a civil cryptography license (Decree 58/2016/NĐ-CP & Decree 53/2018/NĐ-CP). |
| `equipment` | Register and verify dedicated cryptographic hardware or HSM appliance (Article 12 Law 05/2011/QH13). |
| `incident` | Report a cryptographic security incident, tamper alert, or key breach (Article 20 Law 05/2011/QH13). |
| `list` | List cipher systems, keys, civil licenses, certified equipment, and incident reports. |
| `status` | Get aggregate telemetry metrics on national cipher network readiness, key health, and civil crypto compliance. |
