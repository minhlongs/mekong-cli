# /ecom — E-Commerce — Vietnamese Cross-Border E-Commerce, Overseas Supplier Tax & Marketplace Compliance

E-Commerce — Vietnamese Cross-Border E-Commerce, Overseas Supplier Tax & Marketplace Compliance.

## Usage

```bash
// turbo
mekong ecom $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `fct` | Tính thuế Nhà thầu Nước ngoài (FCT - VAT & CIT) cho dịch vụ kỹ thuật số xuyên biên giới. |
| `audit` | Thẩm định điều kiện cấp phép và tuân thủ pháp luật sàn/website TMĐT theo Nghị định 52/2013 & 85/2021. |
| `order` | Quyết toán tài chính đơn hàng sàn TMĐT, tính thực nhận của shop & xuất hóa đơn điện tử. |
| `parcel` | Thẩm định nghĩa vụ thuế bưu kiện chuyển phát nhanh TMĐT xuyên biên giới (ngưỡng miễn thuế $\le 1$ tr). |
| `list` | Truy vấn danh mục sàn TMĐT, tờ khai thuế FCT, đơn hàng hoặc bưu kiện xuyên biên giới. |
| `status` | Hiển thị tổng quan các chỉ số điều hành TMĐT và nghĩa vụ thuế số xuyên biên giới. |
