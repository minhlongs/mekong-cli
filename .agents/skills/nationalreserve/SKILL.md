# /nationalreserve — National Reserves — Vietnamese National Reserves, Strategic Stockpiling & Emergency Relief Suite (Luật Dự trữ quốc gia 2012)

National Reserves — Vietnamese National Reserves, Strategic Stockpiling & Emergency Relief Suite (Luật Dự trữ quốc gia 2012).

## Usage

```bash
// turbo
mekong nationalreserve $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `warehouse` | Register a state reserve strategic storage depot / warehouse. |
| `intake` | Record commodity intake into national reserve inventory with automated rotation deadline. |
| `inspect` | Record technical inspection results of reserve stock per QCVN standards. |
| `relief` | Execute emergency dispatch & relief allocation of national reserve commodities. |
| `rotate` | Schedule statutory stock rotation (xuất đổi hàng/xoay vòng) under Art 45 Law 22/2012/QH13. |
| `replenish` | Record completion of stock rotation by replenishing fresh inventory. |
| `list` | List state reserve warehouses, inventories, relief allocations, and rotation plans. |
| `status` | Get aggregate telemetry metrics on national reserves and relief operations. |
