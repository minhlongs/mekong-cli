# /swarm — C1 Agent Orchestration: supervisor + multi-agent delegation

C1 Agent Orchestration: supervisor + multi-agent delegation.

## Usage

```bash

```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `run` | Run a goal through the C1 supervisor swarm. |
| `supervise` | Show supervisor plan (decomposition) without executing. |
