# /telemetry — 📊 Autonomous Telemetry, Prometheus & Distributed Tracing

📊 Autonomous Telemetry, Prometheus & Distributed Tracing.

## Usage

```bash
// turbo
mekong telemetry $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `metrics` | Export or inspect Prometheus-compliant metrics. |
| `traces` | View distributed tracing spans, latency timings, and W3C traceparent headers. |
| `export` | Export current Prometheus metrics and trace spans into static artifacts. |
