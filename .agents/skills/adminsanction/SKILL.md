# /adminsanction — AdminSanction — Vietnamese Administrative Sanctions, Statutory Fines & Remedial Measures Suite (Luật XLVPHC 2012/2020 & NĐ 118/2021/NĐ-CP)

AdminSanction — Vietnamese Administrative Sanctions, Statutory Fines & Remedial Measures Suite (Luật XLVPHC 2012/2020 & NĐ 118/2021/NĐ-CP).

## Usage

```bash
// turbo
mekong adminsanction $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `status` | Hiển thị bảng điều khiển khung pháp lý xử lý vi phạm hành chính. |
| `create-case` | Lập hồ sơ vụ việc vi phạm hành chính và kiểm tra thời hiệu xử phạt. |
| `calculate-fine` | Tính toán mức tiền phạt luật định theo Nghị định 118/2021/NĐ-CP và Điều 23 Luật XLVPHC. |
| `check-authority` | Kiểm tra thẩm quyền xử phạt của chức danh theo Điều 38–51 Luật XLVPHC. |
| `remedy` | Tính toán biện pháp khắc phục hậu quả & thu hồi số lợi bất hợp pháp (Điều 28). |
| `decide` | Ban hành quyết định xử phạt vi phạm hành chính chính thức. |
