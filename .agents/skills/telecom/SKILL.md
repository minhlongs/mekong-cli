# /telecom — Telecom — Vietnamese Telecommunications Law 2023, Radio Spectrum Auctions, BTS EMF & OTT Services

Telecom — Vietnamese Telecommunications Law 2023, Radio Spectrum Auctions, BTS EMF & OTT Services.

## Usage

```bash
// turbo
mekong telecom $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `spectrum` | Định giá khởi điểm đấu giá quyền sử dụng băng tần số vô tuyến điện (4G/5G) theo Nghị định 63/2023/NĐ-CP. |
| `ott` | Thẩm định tuân thủ pháp lý dịch vụ OTT viễn thông, Trung tâm dữ liệu & Điện toán đám mây (Luật Viễn thông 2023). |
| `bts` | Đánh giá an toàn bức xạ điện từ trường trạm phát sóng di động (BTS) theo QCVN 08:2020/BTTTT. |
| `number` | Phân bổ tài nguyên kho số viễn thông & tính phí duy trì mã mạng/kho số theo Thông tư 25/2015/TT-BTTTT. |
| `list` | Truy vấn danh mục đấu giá tần số, hồ sơ OTT, trạm BTS hoặc tài nguyên kho số. |
| `status` | Hiển thị tổng quan các chỉ số điều hành viễn thông, đấu giá tần số và dịch vụ OTT. |
