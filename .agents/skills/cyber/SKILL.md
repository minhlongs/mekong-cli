# /cyber — Cyber — Vietnamese Cybersecurity, Critical Information Infrastructure & Network Security Suite

Cyber — Vietnamese Cybersecurity, Critical Information Infrastructure & Network Security Suite.

## Usage

```bash
// turbo
mekong cyber $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `localize` | Thẩm định tuân thủ lưu trữ dữ liệu tại Việt Nam (Data Localization) theo Điều 26 Luật An ninh mạng và Nghị định 53/2022. |
| `level` | Xác định và thẩm định hồ sơ cấp độ an toàn hệ thống thông tin (Cấp độ 1 đến 5) theo Nghị định 85/2016/NĐ-CP. |
| `incident` | Tiếp nhận và điều phối ứng cứu sự cố an toàn thông tin mạng theo quy chuẩn VNCERT/CC (Thông tư 20/2017/TT-BTTTT). |
| `license` | Thẩm tra điều kiện cấp Giấy phép kinh doanh sản phẩm, dịch vụ an toàn thông tin mạng (Luật ATTTM 2015). |
| `list` | Tra cứu danh mục hồ sơ an ninh mạng, lưu trữ dữ liệu, cấp độ hệ thống và sự cố. |
| `status` | Báo cáo chỉ số telemetry tổng hợp hệ thống an ninh mạng quốc gia. |
