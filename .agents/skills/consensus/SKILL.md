# /consensus — 🗳️ Multi-Agent Consensus Protocol & Swarm Debate

🗳️ Multi-Agent Consensus Protocol & Swarm Debate.

## Usage

```bash
// turbo
mekong consensus $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `vote` | Execute a multi-agent quorum vote on a proposal. |
| `debate` | Conduct a structured multi-round debate with synthetic consensus resolution. |
| `history` | View recent consensus ballots and debate sessions from local ledger. |
