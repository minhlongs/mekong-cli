# /environment — Environment — Vietnamese Environmental Protection, EIA & Carbon Credits

Environment — Vietnamese Environmental Protection, EIA & Carbon Credits.

## Usage

```bash
// turbo
mekong environment $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `classify` | Phân loại mức độ tác động môi trường của dự án (Nhóm I, II, III, IV) theo Điều 28 Luật BVMT 2020. |
| `license` | Cấp Giấy phép Môi trường (GPMT) tích hợp theo quy định tại Điều 39-49 Luật BVMT 2020. |
| `ghg` | Kiểm kê khí nhà kính Scope 1/2/3 và tính toán bù trừ tín chỉ carbon (Nghị định 06/2022/NĐ-CP). |
| `epr` | Tính toán trách nhiệm mở rộng của nhà sản xuất (EPR) và đóng góp Quỹ BVMT Việt Nam (VEPF). |
| `monitor` | Giám sát số liệu quan trắc tự động liên tục đối chiếu với QCVN 40:2011 & QCVN 19:2009. |
| `list` | Tra cứu danh mục dự án ĐTM, Giấy phép Môi trường, kiểm kê KNK, khai báo EPR. |
| `status` | Xuất báo cáo trạng thái hệ thống bảo vệ môi trường và tín chỉ carbon định dạng JSON. |
