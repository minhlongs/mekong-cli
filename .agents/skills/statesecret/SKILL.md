# /statesecret — State Secret — Vietnamese State Secrets & Classified Protection Suite (Luật Bảo vệ bí mật nhà nước 2018)

State Secret — Vietnamese State Secrets & Classified Protection Suite (Luật Bảo vệ bí mật nhà nước 2018).

## Usage

```bash
// turbo
mekong statesecret $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `classify` | Register and classify a state secret document or carrier under Article 10 of Law 35/2018/QH14. |
| `authorize` | Authorize access, copying, extracting, or taking secret documents out of headquarters (Articles 11, 14, 15). |
| `adjust` | Execute declassification, grade adjustment, or protection term extension (Articles 20, 21, 22). |
| `destruct` | Record secure destruction of classified documents or carriers pursuant to Article 23 Law 35/2018/QH14. |
| `incident` | Report and investigate a state secret disclosure or compromise incident (Article 26 & Criminal Code Arts 337/338). |
| `list` | List state secret items, authorizations, declassification records, destructions, and incidents. |
| `status` | Get aggregate telemetry metrics on state secrets protection and compliance readiness. |
