# /forestry — Forestry — Vietnamese Forestry Law 2017, VNTLAS Timber Legality, FSC & Forest Carbon Sinks

Forestry — Vietnamese Forestry Law 2017, VNTLAS Timber Legality, FSC & Forest Carbon Sinks.

## Usage

```bash
// turbo
mekong forestry $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `plot` | Đăng ký khu rừng / lô rừng quản lý bền vững và chứng chỉ FSC/PEFC. |
| `timber` | Thẩm tra nguồn gốc gỗ hợp pháp theo VNTLAS & cấp phép FLEGT/CITES xuất khẩu. |
| `afforestation` | Tính toán diện tích trồng rừng thay thế và nộp Quỹ Bảo vệ & Phát triển Rừng (VNFF). |
| `pfes` | Tính chi trả dịch vụ môi trường rừng (PFES) và giá trị tín chỉ carbon ERPA World Bank. |
| `fire` | Dự báo cấp nguy cơ cháy rừng theo chỉ số khí tượng (Cấp I đến Cấp V). |
| `list` | Tra cứu danh mục khu rừng, lô gỗ VNTLAS, trồng rừng thay thế, PFES và cảnh báo cháy. |
| `status` | Báo cáo tổng quan trạng thái cơ sở dữ liệu và chỉ số ngành lâm nghiệp. |
