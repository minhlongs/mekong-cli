# /tools — Tools: dynamic tool registry & discovery

Tools: dynamic tool registry & discovery.

## Usage

```bash
// turbo
mekong tools $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `list` | List all registered tools. |
| `discover` | Auto-discover tools from a CLI's --help output. |
| `run` | Execute a registered tool. |
| `stats` | Show tool registry statistics. |
| `video` | Sophia AI Video Factory — RaaS video generation engine for Vietnam |
