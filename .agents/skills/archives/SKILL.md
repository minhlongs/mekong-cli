# /archives — Archives — Vietnamese Archives, Digital Records & State Secrets Declassification Suite

Archives — Vietnamese Archives, Digital Records & State Secrets Declassification Suite.

## Usage

```bash
// turbo
mekong archives $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `seal` | Niêm phong tài liệu lưu trữ điện tử theo Thông tư 02/2019/TT-BNV & Điều 13-17 Luật Lưu trữ 2024. |
| `appraise` | Thẩm định thời hạn bảo quản và phê duyệt tiêu hủy tài liệu hết giá trị (Điều 18-22 Luật Lưu trữ 2024). |
| `declassify` | Rà soát và thực hiện thủ tục giải mật tài liệu bí mật nhà nước (Luật BVBMNN 2018 & Luật Lưu trữ 2024). |
| `practitioner` | Thẩm tra tiêu chuẩn cấp Chứng chỉ hành nghề lưu trữ theo Điều 54-57 Luật Lưu trữ 2024. |
| `warehouse` | Kiểm tra điều kiện môi trường và an toàn cơ sở vật chất kho lưu trữ tài liệu. |
| `list` | Tra cứu danh mục hồ sơ lưu trữ điện tử, thẩm định thời hạn, hồ sơ giải mật và chứng chỉ hành nghề. |
| `status` | Hiển thị tổng quan các chỉ số telemetry lưu trữ số và bảo mật quốc gia. |
