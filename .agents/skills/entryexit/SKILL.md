# /entryexit — EntryExit — Alias for Vietnamese Immigration, Entry, Exit & Border Control Suite

EntryExit — Alias for Vietnamese Immigration, Entry, Exit & Border Control Suite.

## Usage

```bash
// turbo
mekong entryexit $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `visa` | Register or evaluate foreigner visa application under Law 47/2014 & Law 23/2023. |
| `residence` | Issue or manage Temporary (TRC) or Permanent (PRC) Residence Card. |
| `border` | Log and verify Entry/Exit border movement with automated security screening. |
| `restriction` | Impose or register Entry Suspension or Exit Postponement order. |
| `passport` | Issue or register Vietnamese Citizen Electronic Passport and Autogate enrollment. |
| `list` | List immigration and border management records by category. |
| `status` | Show Vietnamese immigration, border control and passport telemetry. |
