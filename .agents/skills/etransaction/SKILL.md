# /etransaction — E-Transaction — Vietnamese Electronic Transactions, Digital Signatures, Trust Services & Data Messages Suite

E-Transaction — Vietnamese Electronic Transactions, Digital Signatures, Trust Services & Data Messages Suite.

## Usage

```bash
// turbo
mekong etransaction $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `message` | Tạo và lưu trữ thông điệp dữ liệu có giá trị pháp lý theo Luật GDĐT 2023 Điều 9-11. |
| `verify-msg` | Xác minh tính toàn vẹn và giá trị chứng cứ của thông điệp dữ liệu theo Điều 9-11. |
| `convert` | Chuyển đổi văn bản giấy sang thông điệp dữ liệu điện tử theo Điều 12 Luật GDĐT 2023. |
| `sign` | Tạo chữ ký điện tử / chữ ký số an toàn theo Luật GDĐT 2023 Điều 21-25 & NĐ 130/2018/NĐ-CP. |
| `verify-sig` | Xác minh tính hợp lệ và tuân thủ pháp lý của chữ ký số / chữ ký điện tử theo Điều 22-23. |
| `trust` | Cấp dấu thời gian (RFC 3161) hoặc chứng thư dịch vụ tin cậy theo Điều 28-32. |
| `contract` | Khởi tạo hợp đồng điện tử theo Luật GDĐT 2023 Điều 34-38. |
| `sign-contract` | Ký hợp đồng điện tử và tự động chuyển đổi trạng thái hiệu lực khi đủ chữ ký. |
| `ceca` | Gắn dấu chứng thực CeCA lên hợp đồng điện tử theo Nghị định 52/2024/NĐ-CP. |
| `list` | Liệt kê danh sách thông điệp dữ liệu, chữ ký số, dấu tin cậy và hợp đồng điện tử. |
| `status` | Kiểm tra chỉ số đo lường và tình trạng vận hành hệ thống giao dịch điện tử. |
