# /crop — Crop — Vietnamese Crop Cultivation, Plant Protection, Pesticides & Agricultural Quarantine Suite

Crop — Vietnamese Crop Cultivation, Plant Protection, Pesticides & Agricultural Quarantine Suite.

## Usage

```bash
// turbo
mekong crop $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `puc` | Thẩm định điều kiện cấp Mã số vùng trồng (PUC) xuất khẩu theo Luật Trồng trọt 2018 và TCCS 774:2020/BVTV. |
| `pesticide` | Kiểm tra tính hợp pháp của hoạt chất thuốc BVTV và thời gian cách ly (PHI) theo Thông tư 09/2023/TT-BNNPTNT. |
| `phyto` | Thẩm định và cấp Giấy chứng nhận Kiểm dịch thực vật xuất nhập khẩu (Luật BV&KDTV 2013). |
| `store` | Thẩm tra điều kiện cấp Giấy chứng nhận đủ điều kiện buôn bán thuốc BVTV (Điều 63 Luật BV&KDTV 2013). |
| `list` | Tra cứu danh mục mã số vùng trồng, kiểm tra thuốc BVTV, chứng thư kiểm dịch và cửa hàng thuốc BVTV. |
| `status` | Báo cáo chỉ số telemetry tổng hợp quản lý trồng trọt, mã vùng trồng và bảo vệ thực vật quốc gia. |
