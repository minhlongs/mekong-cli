# /memory-mesh — 🕸️ Federated Memory Mesh & Knowledge Graph

🕸️ Federated Memory Mesh & Knowledge Graph.

## Usage

```bash
// turbo
mekong memory-mesh $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `index` | Index codebase entities, historical ballots, and execution patterns into memory mesh. |
| `stats` | Display health and telemetry metrics of the federated memory subsystem. |
| `graph` | Traverse and display relational knowledge graph around an entity. |
