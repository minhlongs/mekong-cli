# /judicialrecord — JudicialRecord — Vietnamese Judicial Records & Criminal Clearance Suite (Luật Lý lịch tư pháp 2009)

JudicialRecord — Vietnamese Judicial Records & Criminal Clearance Suite (Luật Lý lịch tư pháp 2009).

## Usage

```bash
// turbo
mekong judicialrecord $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `request` | Submit application for Judicial Record Certificate (Phiếu lý lịch tư pháp số 1 hoặc số 2). |
| `conviction` | Record criminal conviction into National Judicial Database. |
| `clearance` | Evaluate criminal record remission (Xóa án tích) under Articles 70-73 Penal Code 2015. |
| `prohibition` | Record prohibition from holding positions or managing enterprises. |
| `issue` | Synthesize criminal history and issue official electronic Judicial Record Certificate. |
| `list` | List judicial record entries by category. |
| `status` | Show national judicial record and criminal clearance statistics. |
