# /autonomous — Autonomous: AGI loop control

Autonomous: AGI loop control.

## Usage

```bash
// turbo
mekong autonomous $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `status` | Show Consciousness Score and subsystem health (AGI v2: all 9 subsystems). |
| `run` | Run a single autonomous cycle with full AGI v2 pipeline. |
| `resume` | Resume autonomous operations after halt. |
| `reflect` | Show reflection engine stats and recent reflections. |
| `world` | Show current world model snapshot. |
| `predict` | Predict side effects of an action before executing. |
