# /admiralty — Admiralty — Vietnamese Maritime Court, Admiralty Jurisdiction, Vessel Arrest & Maritime Liens Suite

Admiralty — Vietnamese Maritime Court, Admiralty Jurisdiction, Vessel Arrest & Maritime Liens Suite.

## Usage

```bash
// turbo
mekong admiralty $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `vessel` | Đăng ký tàu biển thương mại vào Sổ đăng ký tàu biển quốc gia theo Chương II Bộ luật Hàng hải. |
| `arrest` | Nộp đơn yêu cầu bắt giữ tàu biển và thẩm tra biện pháp bảo đảm tài chính theo Pháp lệnh 05/2008. |
| `lien` | Xác lập và xếp hạng Quyền cầm giữ hàng hải (Maritime Liens) theo Điều 41-42 Bộ luật Hàng hải. |
| `collision` | Phân định trách nhiệm bồi thường thiệt hại do đâm va tàu biển theo Điều 286-291 Bộ luật Hàng hải. |
| `ga` | Tính toán phân bổ Tổn thất chung (General Average) theo Quy tắc York-Antwerp 2016 & Điều 300-307. |
| `list` | Tra cứu danh mục tàu biển, lệnh bắt giữ, quyền cầm giữ và hồ sơ đâm va hàng hải. |
| `status` | Hiển thị tổng quan các chỉ số telemetry hoạt động tư pháp hàng hải toàn quốc. |
