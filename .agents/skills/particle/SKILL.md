# /particle — ZenOS particle lifecycle management, behavior graph, and AI cells

ZenOS particle lifecycle management, behavior graph, and AI cells.

## Usage

```bash
// turbo
mekong particle $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `init` | Create a new ZenOS particle from the skeleton template. |
| `list` | List registered ZenOS particles. |
| `connect` | Establish a trust relationship between two particles. |
| `status` | Show a particle's network status — connections, trust, and collusion. |
| `graph` | Behavior graph -- trust & collusion detection |
| `cell` | AI Cell Runtime Engine -- execute and audit autonomous cells |
| `zenpay` | Constitutional Treasury -- record transactions and manage budgets |
