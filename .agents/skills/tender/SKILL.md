# /tender — Tender — Vietnamese public procurement, bidding dossiers & E-GP evaluation

Tender — Vietnamese public procurement, bidding dossiers & E-GP evaluation.

## Usage

```bash
// turbo
mekong tender $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `method` | Thẩm định và tư vấn hình thức lựa chọn nhà thầu theo Luật Đấu thầu 2023 (Chỉ định thầu, Chào hàng cạnh tranh, Đấu thầu rộng rãi). |
| `create` | Tạo lập và phát hành gói thầu E-HSMT trên Hệ thống Mạng Đấu thầu Quốc gia. |
| `eval` | Đánh giá hồ sơ dự thầu E-HSDT theo quy trình 4 bước của Nghị định 24/2024/NĐ-CP. |
| `collusion-scan` | Quét và phát hiện dấu hiệu vi phạm điều cấm thông thầu / dàn xếp giá theo Điều 16 Luật Đấu thầu 2023. |
| `list` | Truy vấn danh mục các gói thầu điện tử đã phát hành trên hệ thống. |
| `status` | Tra cứu trạng thái cơ sở dữ liệu đấu thầu điện tử và hiệu quả tiết kiệm ngân sách. |
