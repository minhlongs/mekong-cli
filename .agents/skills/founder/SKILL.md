# /founder — Founder genome assessment: personality, risk tolerance, and bias profiling

Founder genome assessment: personality, risk tolerance, and bias profiling.

## Usage

```bash
// turbo
mekong founder $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `assess` | Assess a founder genome and store it in the database. |
| `review` | Load and display a founder genome profile. |
| `list` | List all assessed founders with optional risk filtering. |
| `analyze` | Synthesize psychometric strengths, blindspots, and team recommendations. |
