# /founder — Founder genome assessment: personality, risk tolerance, and bias profiling

Founder genome assessment: personality, risk tolerance, and bias profiling.

## Usage

```bash
// turbo
mekong founder $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `assess` | Assess a founder genome and store it in the behaviour graph. |
| `review` | Load and display a founder genome from the behaviour graph. |
| `list` | List all assessed founders in the behaviour graph. |
