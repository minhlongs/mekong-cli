# /automotive — Automotive — Vietnamese Automotive Manufacturing, Type Approval, Emission & EV Suite

Automotive — Vietnamese Automotive Manufacturing, Type Approval, Emission & EV Suite.

## Usage

```bash
// turbo
mekong automotive $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `license` | Thẩm tra điều kiện sản xuất, lắp ráp ô tô theo Nghị định 116/2017/NĐ-CP & Nghị định 17/2020/NĐ-CP. |
| `vta` | Thẩm định Chứng nhận kiểu loại ô tô (VTA) theo Thông tư 25/2019/TT-BGTVT và chuẩn Euro 5. |
| `rvc` | Tính toán tỷ lệ hàm lượng giá trị khu vực RVC theo Hiệp định thương mại ATIGA Form D. |
| `battery` | Kiểm toán an toàn pin xe điện và hệ thống điện cao áp theo QCVN 91:2019/BGTVT. |
| `inspect` | Tính toán chu kỳ và thời hạn đăng kiểm xe cơ giới theo Thông tư 08/2023/TT-BGTVT. |
| `list` | Tra cứu danh mục cơ sở sản xuất, hồ sơ kiểu loại VTA, kiểm định pin EV, hoặc sổ theo dõi chu kỳ đăng kiểm. |
| `status` | Xuất báo cáo trạng thái hệ thống ngành công nghiệp ô tô dạng JSON. |
