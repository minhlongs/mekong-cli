# /police — Police — Vietnamese People's Public Security & Grassroots Security Forces Suite (Luật CAND & Luật Lực lượng tham gia bảo vệ ANTT ở cơ sở)

Police — Vietnamese People's Public Security & Grassroots Security Forces Suite (Luật CAND & Luật Lực lượng tham gia bảo vệ ANTT ở cơ sở).

## Usage

```bash
// turbo
mekong police $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `officer` | Register an officer of the People's Public Security (Law on People's Public Security 2018). |
| `team` | Register a grassroots security team under Law No. 30/2023/QH15 and Decree No. 40/2024/NĐ-CP. |
| `incident` | Report a public security or social order incident (Article 16 Law 37/2018 & Law 30/2023). |
| `patrol` | Log a joint security patrol mission (Circular 14/2024/TT-BCA). |
| `residence` | Record an administrative household residence and temporary stay inspection (Law on Residence 2020). |
| `list` | List records across officers, grassroots teams, incidents, patrols, and residence checks. |
| `status` | Get aggregate telemetry metrics on People's Public Security and Grassroots Security forces. |
