# /privacy — Privacy — Vietnamese Personal Data Protection Decree (PDPD Nghị định 13/2023/NĐ-CP) & cross-border transfer compliance

Privacy — Vietnamese Personal Data Protection Decree (PDPD Nghị định 13/2023/NĐ-CP) & cross-border transfer compliance.

## Usage

```bash
// turbo
mekong privacy $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `audit` | Đánh giá mức độ tuân thủ toàn diện Nghị định 13/2023/NĐ-CP của doanh nghiệp. |
| `dpia` | Lập hồ sơ Đánh giá tác động xử lý dữ liệu cá nhân (DPIA) theo Mẫu số 04 gửi A05 - Bộ Công an (Điều 24). |
| `transfer` | Thẩm định hồ sơ chuyển dữ liệu cá nhân ra nước ngoài theo Điều 25 Nghị định 13/2023/NĐ-CP. |
| `breach` | Ghi nhận và kích hoạt quy trình ứng phó sự cố rò rỉ dữ liệu cá nhân trong thời hạn 72h (Điều 26). |
| `dsar` | Xử lý yêu cầu thực thi quyền của chủ thể dữ liệu (DSAR) theo Điều 9 Nghị định 13/2023/NĐ-CP. |
| `list` | Truy vấn danh mục hồ sơ DPIA, chuyển dữ liệu ra nước ngoài, sự cố vi phạm hoặc yêu cầu DSAR. |
| `status` | Truy vấn các chỉ số giám sát bảo vệ dữ liệu cá nhân theo Nghị định 13/2023/NĐ-CP. |
