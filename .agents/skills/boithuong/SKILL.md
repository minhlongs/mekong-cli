# /boithuong — BoiThuong — Alias for Vietnamese Non-Contractual Civil Liability & Tort Compensation Suite

BoiThuong — Alias for Vietnamese Non-Contractual Civil Liability & Tort Compensation Suite.

## Usage

```bash
// turbo
mekong boithuong $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `status` | Display statutory parameters and legal caps dashboard. |
| `create-case` | Create a new non-contractual tort liability compensation case. |
| `calculate-health` | Calculate statutory compensation for harm to health (Điều 590 BLDS & NQ 02/2022). |
| `calculate-life` | Calculate statutory compensation for loss of life (Điều 591, 593 BLDS & NQ 02/2022). |
| `settle` | Record an out-of-court settlement agreement (Biên bản hòa giải thành). |
