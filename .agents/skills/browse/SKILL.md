# /browse — Browse: web automation & page analysis

Browse: web automation & page analysis.

## Usage

```bash
// turbo
mekong browse $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `check` | Check HTTP status of a URL. |
| `analyze` | Full page analysis: title, links, meta tags. |
| `links` | Extract all links from a page. |
