# /usage — 📊 Usage metering and reporting

📊 Usage metering and reporting.

## Usage

```bash
// turbo
mekong usage $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `show` | 📊 Show current period usage. |
| `report` | 📊 Comprehensive usage report with entitlements. |
| `sync` | 🔄 Manually sync local metrics to RaaS Gateway. |
| `overage` | 💰 Calculate overage charges. |
| `export` | 📁 Export usage data to CSV/JSON. |
