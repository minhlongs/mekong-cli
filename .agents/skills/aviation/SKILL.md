# /aviation — Aviation — Vietnamese Civil Aviation, Air Cargo Freight, IATA DGR & Airport Ground Handling

Aviation — Vietnamese Civil Aviation, Air Cargo Freight, IATA DGR & Airport Ground Handling.

## Usage

```bash
// turbo
mekong aviation $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `flight` | Đăng ký lịch trình chuyến bay & phân bổ slot bến đỗ tàu bay tại cảng hàng không. |
| `cargo` | Tính toán Trọng lượng tính cước (Chargeable Weight) theo chuẩn IATA & phân loại bảo quản. |
| `tariff` | Tính toán phí cất hạ cánh, đỗ tàu bay, soi chiếu an ninh & phục vụ mặt đất (Thông tư 53/2019/TT-BGTVT). |
| `dg` | Thẩm định tờ khai hàng nguy hiểm (IATA DGR / ICAO Annex 18) & kiểm tra lệnh cấm trên tàu bay khách. |
| `list` | Truy vấn danh mục lịch bay, vận đơn hàng không e-AWB hoặc tờ khai hàng nguy hiểm. |
| `status` | Truy vấn các chỉ số giám sát vận hành hàng không và logistics hàng hóa. |
