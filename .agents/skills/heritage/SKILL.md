# /heritage — Heritage — Vietnamese Cultural Heritage, Antiquities & National Treasures Suite

Heritage — Vietnamese Cultural Heritage, Antiquities & National Treasures Suite.

## Usage

```bash
// turbo
mekong heritage $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `relic` | Thẩm tra khu vực bảo vệ di tích và tuân thủ xây dựng theo Điều 27-32 Luật Di sản văn hóa 2024. |
| `artifact` | Đăng ký di vật, cổ vật và thẩm định tiêu chuẩn Bảo vật Quốc gia (Điều 39-44 Luật Di sản văn hóa 2024). |
| `excavate` | Thẩm định cấp phép thăm dò, khai quật khảo cổ học theo Điều 35-38 Luật Di sản văn hóa 2024. |
| `exhibit` | Kiểm tra điều kiện trưng bày bảo tàng và xuất khẩu tạm thời triển lãm nước ngoài (Điều 47-53). |
| `list` | Tra cứu danh mục di tích xếp hạng, cổ vật đăng ký, giấy phép khảo cổ và đợt trưng bày bảo tàng. |
| `status` | Hiển thị tổng quan các chỉ số telemetry bảo tồn di sản văn hóa quốc gia. |
