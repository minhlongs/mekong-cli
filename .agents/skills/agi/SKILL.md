# /agi — Tom Hum AGI daemon management

Tom Hum AGI daemon management.

## Usage

```bash
// turbo
mekong agi $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `start` | Start the Tom Hum AGI daemon. |
| `stop` | Stop the Tom Hum AGI daemon. |
| `status` | 🧠 Show AGI health, score, and 9-subsystem dashboard. |
| `metrics` | Show detailed AGI metrics. |
| `mission` | Dispatch a mission to the daemon via tasks/ directory. |
| `logs` | View Tom Hum daemon logs. |
