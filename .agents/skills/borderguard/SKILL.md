# /borderguard — Border Guard — Vietnamese National Border, Territorial Sovereignty & Border Guard Defense Suite (Luật Biên phòng Việt Nam 2020)

Border Guard — Vietnamese National Border, Territorial Sovereignty & Border Guard Defense Suite (Luật Biên phòng Việt Nam 2020).

## Usage

```bash
// turbo
mekong borderguard $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `marker` | Register and inspect a national border landmark or marker. |
| `permit` | Issue an entry permit to access the border belt or restricted border area (Decree 34/2014/NĐ-CP). |
| `patrol` | Log a border guard patrol mission or joint bilateral patrol. |
| `gate` | Register a border gate or immigration checkpoint. |
| `incident` | Report a border incident, territorial encroachment, smuggling, or illegal crossing. |
| `list` | List border markers, permits, patrol missions, gates, and incidents. |
| `status` | Get aggregate telemetry metrics on border defense readiness and sovereignty enforcement. |
