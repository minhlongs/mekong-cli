# /bailiff — Bailiff — Vietnamese Bailiff, Evidence Protocol (Vi Bằng) & Civil Enforcement Suite

Bailiff — Vietnamese Bailiff, Evidence Protocol (Vi Bằng) & Civil Enforcement Suite.

## Usage

```bash
// turbo
mekong bailiff $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `protocol` | Lập Vi bằng chứng cứ trực tiếp theo Nghị định 08/2020/NĐ-CP Điều 36-41. |
| `serve` | Tống đạt văn bản tố tụng của Tòa án, Viện kiểm sát và Cơ quan THADS theo Điều 32-35. |
| `verify` | Xác minh điều kiện thi hành án (tài khoản ngân hàng, bất động sản, xe cơ giới) theo Điều 43-50. |
| `enforce` | Tổ chức trực tiếp thi hành bản án, quyết định dân sự theo yêu cầu của đương sự (Điều 51-56). |
| `list` | Tra cứu danh mục Vi bằng, hồ sơ tống đạt, biên bản xác minh tài sản và thi hành án. |
| `status` | Hiển thị tổng quan các chỉ số telemetry hoạt động Thừa phát lại và thi hành án toàn quốc. |
