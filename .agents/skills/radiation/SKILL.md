# /radiation — Radiation — Vietnamese Radiation Safety, Radioactive Sources & Nuclear Technology Suite

Radiation — Vietnamese Radiation Safety, Radioactive Sources & Nuclear Technology Suite.

## Usage

```bash
// turbo
mekong radiation $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `license` | Thẩm tra hồ sơ cấp Giấy phép tiến hành công việc bức xạ theo Nghị định 142/2020/NĐ-CP và Luật Năng lượng nguyên tử. |
| `dose` | Ghi nhận và đánh giá kết quả đo liều kế cá nhân của nhân viên bức xạ theo Thông tư 19/2012/TT-BKHCN. |
| `source` | Giám sát an ninh nguồn phóng xạ và kiểm tra định vị GPS thời gian thực theo Quyết định 446/QĐ-BKHCN. |
| `xray` | Kiểm tra kiểm định định kỳ và đảm bảo chất lượng (QA) máy X-quang y tế theo TTLT 13/2014/TTLT-BKHCN-BYT. |
| `list` | Tra cứu danh mục hồ sơ cấp phép bức xạ, đo liều cá nhân, an ninh nguồn và kiểm định X-quang. |
| `status` | Báo cáo chỉ số telemetry tổng hợp hệ thống an toàn bức xạ và an ninh nguồn phóng xạ quốc gia. |
