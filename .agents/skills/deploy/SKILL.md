# /deploy — Deploy phase: verify gates -> ship/hold

Deploy phase: verify gates -> ship/hold.

## Usage

```bash
// turbo
mekong deploy $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `run` | Deploy application to specified platform |
| `status` | Check deployment status. |
| `rollback` | Rollback deployment to a previous version |
| `new` | Start the deploy phase for <feature>. |
