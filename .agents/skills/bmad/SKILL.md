# /bmad — BMAD workflow management

BMAD workflow management.

## Usage

```bash
// turbo
mekong bmad $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `list` | List available BMAD workflows. |
| `info` | Show detailed workflow information. |
| `catalog` | Build and cache workflow catalog. |
| `search` | Search workflows by name or description. |
| `run` | Execute a BMAD workflow. |
