# /collab — Collab: multi-agent collaboration & debate

Collab: multi-agent collaboration & debate.

## Usage

```bash
// turbo
mekong collab $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `agents` | List registered collaboration agents. |
| `stats` | Show collaboration statistics. |
| `debate` | 🤝 Start a multi-agent debate on a topic. |
| `review` | 🤝 Submit a code review for a task. |
