# /marriage — Marriage — Vietnamese Marriage, Matrimonial Property Regimes & Family Law Suite (Luật HNGĐ 2014)

Marriage — Vietnamese Marriage, Matrimonial Property Regimes & Family Law Suite (Luật HNGĐ 2014).

## Usage

```bash
// turbo
mekong marriage $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `register` | Register legal marriage with statutory age, consent, and monogamy verification. |
| `prenuptial` | Establish or record agreed matrimonial property regime (prenuptial agreement). |
| `asset` | Record property into matrimonial asset inventory (common vs separate property). |
| `divorce` | File divorce petition with Article 51(3) statutory protection for pregnant/nursing mothers. |
| `custody` | Process child custody and monthly child support order under Articles 81-84 & 110-119. |
| `settle` | Settle divorce and liquidate matrimonial property under Article 59. |
| `search` | Search marriage registrations and divorce records. |
| `list` | List marriage and family records by category. |
| `status` | Show national marriage, divorce, and family statistics. |
