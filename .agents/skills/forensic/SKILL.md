# /forensic — Forensic — Vietnamese Judicial Expertise, Forensic Assessment & Electronic Evidence Suite

Forensic — Vietnamese Judicial Expertise, Forensic Assessment & Electronic Evidence Suite.

## Usage

```bash
// turbo
mekong forensic $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `expert` | Đăng ký và thẩm tra hồ sơ Giám định viên tư pháp theo Điều 7 Luật Giám định tư pháp. |
| `solicit` | Tiếp nhận và lập hồ sơ trưng cầu giám định tư pháp theo Điều 25-26 Luật GĐTP. |
| `conclude` | Ban hành Kết luận giám định tư pháp chuẩn hóa theo Điều 32 Luật Giám định tư pháp. |
| `custody` | Thẩm tra và xác lập chuỗi bảo quản chứng cứ kỹ thuật số (Chain of Custody) theo Điều 99, 107 BLTTHS 2015. |
| `list` | Tra cứu danh mục giám định viên, quyết định trưng cầu, bản kết luận và chuỗi chứng cứ điện tử. |
| `status` | Hiển thị tổng quan các chỉ số telemetry hoạt động giám định tư pháp toàn quốc. |
