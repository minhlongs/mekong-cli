# /sports — Sports — Vietnamese Physical Training, Sports, Professional Athletics & Anti-Doping Suite

Sports — Vietnamese Physical Training, Sports, Professional Athletics & Anti-Doping Suite.

## Usage

```bash
// turbo
mekong sports $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `contract` | Đăng ký và thẩm định hợp đồng lao động VĐV chuyên nghiệp, chuyển nhượng theo Điều 32, 33 Luật TDTT. |
| `doping` | Xử lý kết quả kiểm tra Doping và đánh giá chế tài xử phạt theo WADA Code & Thông tư 17/2019. |
| `extreme` | Thẩm định điều kiện an toàn và cấp phép cơ sở kinh doanh thể thao mạo hiểm theo Thông tư 04/2019. |
| `tournament` | Thẩm tra điều kiện an toàn và phê duyệt tổ chức giải thi đấu thể thao theo Điều 37, 38 Luật TDTT. |
| `list` | Tra cứu danh mục hồ sơ hợp đồng VĐV, kết quả doping, giấy phép thể thao mạo hiểm và giải đấu. |
| `status` | Hiển thị tổng quan các chỉ số telemetry thể thao và phòng chống doping quốc gia. |
