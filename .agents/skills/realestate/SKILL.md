# /realestate — RealEstate — Vietnamese commercial real estate, industrial land leasing & QCVN 01:2021 density compliance

RealEstate — Vietnamese commercial real estate, industrial land leasing & QCVN 01:2021 density compliance.

## Usage

```bash
// turbo
mekong realestate $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `finance` | Tính toán chi phí tài chính thuê BĐS công nghiệp / thương mại, dòng tiền phân kỳ và tiền đặt cọc. |
| `density` | Thẩm tra quy chuẩn mật độ xây dựng (<=70%) và tỷ lệ cây xanh (>=10%) theo QCVN 01:2021/BXD. |
| `audit` | Thẩm định pháp lý dự án BĐS (Due Diligence), điều kiện đưa BĐS vào kinh doanh cho thuê. |
| `draft` | Soạn thảo hợp đồng thuê BĐS thương mại / nhà xưởng theo mẫu chuẩn Nghị định 96/2024/NĐ-CP. |
| `list` | Truy vấn danh bạ BĐS công nghiệp / thương mại đã đăng ký trên hệ thống. |
| `status` | Tra cứu trạng thái cơ sở dữ liệu BĐS công nghiệp và chỉ số hợp đồng thuê. |
