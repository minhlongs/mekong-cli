# /ocop — OCOP — nông sản Việt Nam, xếp hạng sao OCOP & xuất khẩu

OCOP — nông sản Việt Nam, xếp hạng sao OCOP & xuất khẩu.

## Usage

```bash
// turbo
mekong ocop $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `eval` | Đánh giá phân hạng sao OCOP (1 đến 5 sao) theo Quyết định 148/QĐ-TTg. |
| `products` | Tra cứu danh mục sản phẩm OCOP, mã HS và tiêu chuẩn chất lượng. |
| `listing` | Tạo listing B2B thương mại điện tử xuất khẩu và rà soát FTA. |
| `compliance` | Kiểm tra điều kiện kỹ thuật, thuế quan và chứng chỉ xuất khẩu nông sản. |
| `status` | Kiểm tra trạng thái hệ thống OCOP và năng lực xuất khẩu. |
| `analyze` | Analyze a product image/JSON for export-ready features. |
| `export` | Generate B2B export listings from analyzed product data. |
| `list` | Show available export platforms and their status. |
