# /memory — Memory: execution history & learning

Memory: execution history & learning.

## Usage

```bash
// turbo
mekong memory $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `list` | List recent execution memory entries. |
| `stats` | Show memory statistics. |
| `clear` | Clear all execution memory. |
| `search` | 🧠 Search vector memory for similar past goals. |
