# /press — Press — Vietnamese Press, Mass Media, Online Journalism & OTT Broadcasting Suite

Press — Vietnamese Press, Mass Media, Online Journalism & OTT Broadcasting Suite.

## Usage

```bash
// turbo
mekong press $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `credential` | Thẩm tra điều kiện cấp Thẻ nhà báo hoặc bổ nhiệm Tổng biên tập, Trưởng VPĐD. |
| `icp` | Thẩm định tuân thủ giấy phép ICP, trích dẫn bản quyền và chống 'báo hóa' trang tin. |
| `ott` | Thẩm tra điều kiện cấp phép và tuân thủ dịch vụ phát thanh, truyền hình OTT VOD. |
| `correct` | Ghi nhận và giám sát quy trình cải chính, xin lỗi công khai (Điều 42 Luật Báo chí 2016). |
| `list` | Tra cứu danh mục hồ sơ nhân sự báo chí, kiểm toán trang tin ICP, dịch vụ OTT và cải chính. |
| `status` | Hiển thị tổng quan các chỉ số telemetry báo chí, xuất bản và phát thanh truyền hình OTT. |
