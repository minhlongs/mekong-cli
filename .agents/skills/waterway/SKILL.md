# /waterway — Waterway — Vietnamese Inland Waterway Transport, River Ports & Canal Navigation

Waterway — Vietnamese Inland Waterway Transport, River Ports & Canal Navigation.

## Usage

```bash
// turbo
mekong waterway $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `channel` | Đăng ký tuyến luồng kỹ thuật đường thủy nội địa theo chuẩn TCVN 5664:2009. |
| `port` | Đăng ký cảng, bến thủy nội địa và năng lực tiếp nhận phương tiện theo NĐ 08/2021/NĐ-CP. |
| `vessel` | Đăng ký phương tiện thủy nội địa và kiểm tra niên hạn theo Nghị định 111/2014/NĐ-CP. |
| `clearance` | Thẩm định an toàn và cấp Giấy phép rời cảng bến thủy nội địa (Cảng vụ Đường thủy). |
| `captain` | Thẩm tra sát hạch bằng thuyền trưởng thủy nội địa theo Thông tư 40/2020/TT-BGTVT. |
| `freight` | Tính cước vận tải hàng hóa đường thủy nội địa bằng sà lan theo tấn-km / TEU-km. |
| `list` | Tra cứu dữ liệu tuyến luồng, cảng bến, phương tiện, giấy phép rời cảng, bằng thuyền trưởng. |
| `status` | Tra cứu trạng thái telemetry tổng thể của mạng lưới vận tải đường thủy nội địa và cảng bến. |
