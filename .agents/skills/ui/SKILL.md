# /ui — Design intelligence: audit, study, redesign, build, benchmark

Design intelligence: audit, study, redesign, build, benchmark.

## Usage

```bash
// turbo
mekong ui $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `audit` | Deterministic gate run + 9-axis score. Never claims visual evidence. |
| `build` | Emit a tokenized design system (CSS variables) from a DesignDNA file. |
| `study` | Analyse a target -> DesignDNA + .mekong/design/studies/<name>/design.md. |
| `redesign` | Re-fingerprint a study: preserve copy/IA/brand, change macrostructure. |
| `approve` | Approve (or --reject) a study into design memory for agent reuse. |
| `benchmark` | Run the benchmark fixtures and report axis deltas (no single static target). |
