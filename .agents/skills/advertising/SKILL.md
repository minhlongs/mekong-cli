# /advertising — Advertising — Vietnamese Advertising, Media & Digital Marketing Compliance Suite

Advertising — Vietnamese Advertising, Media & Digital Marketing Compliance Suite.

## Usage

```bash
// turbo
mekong advertising $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `check` | Quét và thẩm định tính hợp pháp của nội dung quảng cáo (từ cấm 'nhất', 'số 1', khuyến cáo bắt buộc). |
| `approval` | Cấp Giấy xác nhận nội dung quảng cáo (XNNDQC) cho sản phẩm đặc biệt theo Nghị định 181/2013/NĐ-CP. |
| `billboard` | Thẩm định quy chuẩn xây dựng và lắp đặt biển bảng quảng cáo ngoài trời OOH (QCVN 17:2018/BXD). |
| `takedown` | Giám sát xử lý gỡ bỏ quảng cáo vi phạm xuyên biên giới trong vòng 24 giờ theo Nghị định 70/2021/NĐ-CP. |
| `broadcast` | Kiểm tra tỷ lệ thời lượng quảng cáo phát thanh, truyền hình theo Điều 22 Luật Quảng cáo 2012. |
| `list` | Tra cứu danh sách hồ sơ kiểm tra quảng cáo, giấy phép XNNDQC, vi phạm xuyên biên giới hoặc biển OOH. |
| `status` | Báo cáo chỉ số giám sát và tuân thủ quảng cáo quốc gia. |
