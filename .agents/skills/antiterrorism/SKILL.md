# /antiterrorism — Anti-Terrorism — Vietnamese Anti-Terrorism, Homeland Security & Target Protection Suite (Luật Phòng, chống khủng bố 2013)

Anti-Terrorism — Vietnamese Anti-Terrorism, Homeland Security & Target Protection Suite (Luật Phòng, chống khủng bố 2013).

## Usage

```bash
// turbo
mekong antiterrorism $ARGUMENTS
```

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `target` | Register a vital national security target under Decree 37/2009/NĐ-CP. |
| `alert` | Issue a formal terrorism threat warning pursuant to Law 28/2013/QH13. |
| `plan` | Register a counter-terrorism contingency battle plan for a critical target. |
| `designate` | Designate a terrorist entity subject to immediate asset freeze (Article 34 Law 28/2013/QH13). |
| `freeze` | Record execution of terrorist asset and bank account freeze. |
| `operate` | Log an active tactical counter-terrorism operation or hostage rescue mission. |
| `list` | List protected targets, alerts, emergency plans, sanctions, and operations. |
| `status` | Get aggregate telemetry metrics on homeland security and counter-terrorism readiness. |
