6. Do's & Don'ts

Design rules to maintain consistency across the Nhịp Điệu Xanh ecosystem.

Colors & Contrast

✓

DO

Use Emerald Green (#10B981) for active states, call-to-actions, status tags, and correct verifications.

✕

DON'T

Do not layer Emerald Green text on top of Teal Glow or white surfaces, as it fails contrast ratio check rules.

Typography Usage

✓

DO

Use Outfit font for major titles & headers, Inter for normal text copy, and Fira Code for code blocks, CLI commands, and keys.

✕

DON'T

Do not introduce other web fonts (such as comic or serif fonts) to telemetry dashboards, keeping UI highly technical.

Logo Integrity

✓

DO

Maintain adequate safety margins (minimum 16px equivalent padding) around the logo icon and text variations.

✕

DON'T

Do not skew, stretch, rotate, recolor, or change the component structure of the Nhịp Điệu Xanh symbol.

Layout & Spacing

✓

DO

Follow the 4dp/8dp grid system (4px, 8px, 16px, 24px, 32px, 64px) for all component borders, gaps, margins, and layout gutters.

✕

DON'T

Do not use random pixel margins (e.g. 13px, 27px, or 5px) which break alignment grids in production code.
