# Site Vision: Mekong Platform & Autonomous C-Suite

The public & enterprise web application for Mekong CLI (MIT Open-Core) and Cloud Control Plane. Enables solo developers and Vietnamese SMEs to run autonomous C-Suite agent swarms (CEO, CTO, TaxEngine, PayOS) with cryptographic SHA-256 audit trails, VietQR/Polar billing, and decentralized strategy recipe marketplace.
