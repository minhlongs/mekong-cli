## Style Guide Highlights

### Voice & Tone
- **Confident** but not arrogant
- **Technical** but accessible
- **Visionary** but grounded
- **Educational** not salesy

### Writing Rules
- Use "you" and "your"
- Explain jargon on first use
- Concrete examples > abstract concepts
- Paragraphs under 3 sentences
- Active voice preferred

### Brand Mentions
- Always: "Mekong IDE" (first mention), then "Mekong"
- Tag: @mekongmind on social
- URL: mekongmind.com or mekong-cli GitHub
