## On-Page SEO Checklist

### For Every Blog Post

**Title Tag:**
- [ ] Under 60 characters
- [ ] Includes target keyword (closest to beginning)
- [ ] Compelling click-through (consider SERP competition)
- [ ] Brand name at end (unless homepage)

**Meta Description:**
- [ ] Under 155 characters
- [ ] Includes target keyword
- [ ] Action-oriented language
- [ ] Unique (no duplicates)

**URL Slug:**
- [ ] Short and descriptive
- [ ] Includes target keyword
- [ ] Hyphens, no underscores
- [ ] All lowercase

**Header Structure:**
- [ ] Single H1 (matches title or close variation)
- [ ] H2s for main sections
- [ ] H3s for subsections
- [ ] Target keyword in H2 (at least once)

**Content:**
- [ ] Target keyword in first 100 words
- [ ] Keyword density 0.5-1.5%
- [ ] LSI keywords naturally included
- [ ] 1,500+ words for competitive terms
- [ ] Internal links (3-5 relevant)
- [ ] External links to authoritative sources
- [ ] Original content (not duplicate)

**Images:**
- [ ] Featured image present
- [ ] All images have alt text
- [ ] Alt text describes image (not keyword stuffed)
- [ ] Images optimized (<200KB)
- [ ] WebP format when possible
- [ ] Image file names descriptive

**Schema Markup:**
- [ ] Article schema for blog posts
- [ ] HowTo schema for tutorials
- [ ] FAQ schema for Q&A content
- [ ] VideoObject for video content

## Technical SEO

### Site Speed
- Target: LCP < 2.5 seconds
- Tools: PageSpeed Insights, WebPageTest
- Optimizations:
  - Image compression
  - Code splitting
  - Lazy loading images
  - Minimize render-blocking resources

### Mobile-First
- Mobile-responsive design
- Touch-friendly navigation
- No horizontal scrolling
- Fast mobile page speed

### Indexing
- XML sitemap submitted to Google Search Console
- robots.txt configured correctly
- No orphan pages (all pages linked from somewhere)
- Canonical tags for duplicate content

---

## Link Building Strategy

### Priority 1: Internal Linking
- Ensure every new post links to 3-5 existing posts
- Update old posts to link to new relevant content
- Create "suggested reading" sections

### Priority 2: Natural External Links
- Create link-worthy content (research, tools, data)
- Guest posting on relevant sites
- HARO (Help a Reporter Out) responses
- Podcast interviews with links

### Priority 3: Strategic Outreach
- Link to relevant resources in your content, then contact them
- Partner integrations (Supabase, Ollama, etc.) - co-marketing
- Mention influencers/companies, then reach out

### Avoid
- Link farms
- Paid links
- Directory submissions
- Forum spam

## Monthly SEO Tasks

### Week 1
- Review search console for new opportunities/errors
- Analyze top-performing content (replicate success)
- Check keyword rankings (Ahrefs/SEMrush)

### Week 2
- Create content based on keyword opportunities
- Update old content (refresh, improve, add links)
- Fix technical issues (404s, slow pages)

### Week 3
- Build internal links (new → old content)
- Outreach for link opportunities
- Monitor competitors' new content

### Week 4
- Full SEO audit review
- Plan next month's content
- Update keyword research

## Quarterly SEO Review

### Metrics to Review:
- Total organic traffic (growth %)
- Top 10 keywords count
- Pages with 1,000+ monthly visits
- Average position for target keywords
- Backlink profile growth

### Adjustments:
- Double down on content types performing well
- Pause or revise underperforming content
- Update keyword targets based on performance
- Refresh top 10 posts (re-date, update content)
