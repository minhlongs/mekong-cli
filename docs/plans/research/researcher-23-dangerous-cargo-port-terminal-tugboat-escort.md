## 2. Phase 231: Dangerous Cargo Handling & Port Yard Segregation

### A. Mandatory Direct-Discharge & Dwell Limits (No-Yard Stacking)
Per Decree 58/2017/NĐ-CP (Art 42) & Decree 34/2024/NĐ-CP:
- **Class 1 (Explosives)**: Direct discharge (ship-to-truck / direct barge). Yard storage forbidden. Dwell time on pier apron: max 2h during loading/unloading operations.
- **Class 7 (Radioactive Materials)**: Direct discharge mandatory. No storage allowed within common terminal gates. Dedicated convoy transit within 4h of quay release.
- **Class 5.2 (Organic Peroxides - Temperature Controlled) & Class 2.3 (Toxic Gases)**: Direct-to-truck mandatory. Max allowable apron dwell: 24h under active refrigeration backup and dry-powder deluge standby.
- **General DG Dwell Limits (Classes 2, 3, 4, 5.1, 6.1, 8, 9)**: Maximum yard dwell capped at 72h (transshipment) or 48h (inland import release) before penalty surcharges and forced off-site removal to bonded DG depot.

### C. Emergency Response Buffer Zones
- Isolated DG Pad: Minimum 50m separation from main gate, CFS warehouse, bunker manifold, and residential boundary.
- Bunded containment sump: Sized to 110% capacity of the largest stacked ISO-tank (min 26,000L).
- Water deluge monitor reach: Continuous 1,200 L/min fixed foam/water monitor covering all DG bays within 30m radius.

## 3. Phase 232: Seaport Tugboat Towage & Bollard Pull Allocation

### A. Statutory Harbor Tug Allocation Matrix
Per Circular 39/2023/TT-BGTVT (Art 8, Annex III) & Port Authority (Cảng vụ Hàng hải) Regulations:
| Ship LOA (m) | Equivalent GT / DWT | Minimum Tug Quantity | Min Bollard Pull (BP) per Tug | Min Total Fleet BP (Tonnes) |
|---|---|---|---|---|
| **LOA < 80m** | GT < 2,000 | 0 (Optional / Master discretion) | N/A | 0T |
| **80m <= LOA < 115m** | 2,000 <= GT < 5,000 | 1 Tug | 1,000 HP / ~20T BP | 20T |
| **115m <= LOA < 150m**| 5,000 <= GT < 15,000 | 1-2 Tugs (Pilot choice) | 1,500 HP / ~30T BP | 40T - 50T |
| **150m <= LOA < 175m**| 15,000 <= GT < 30,000 | 2 Tugs | 2,000 HP / ~35T BP | 70T |
| **175m <= LOA < 200m**| 30,000 <= GT < 50,000 | 2 Tugs | 3,000 HP / ~45T BP | 90T |
| **200m <= LOA < 250m**| 50,000 <= GT < 80,000 | 3 Tugs | 3,600 HP / ~50T BP | 130T - 150T |
| **LOA >= 250m** | GT >= 80,000 (Megamax) | 3-4 Tugs (Escort + Stern) | 4,500-6,000 HP / ~60T-80T BP | 200T - 260T+ |

### B. Weather / Hydrological Environmental Cutoffs
Towage and pilotage operations cease or mandate upgraded tug configurations under:
1. **Wind / Sea State**: Beaufort Scale >= Force 6 (Wind speed > 12.0 m/s / > 22-27 knots). Berthing aborted unless approved by Maritime Administration with +1 standby tug (>= 60T BP).
2. **Current Speed**: Tidal current velocity > 3.0 knots across approach fairway (e.g., Luồng Soài Rạp, Cái Mép - Thị Vải). Berthing restricted to slack water (+/- 45 mins high/low water).
3. **Restricted Visibility**: Fog/rain visibility < 0.5 NM: All tug operations suspended.

### C. Statutory Escort Surcharges (Circular 39/2023/TT-BGTVT)
- **Active Channel Escort**: Tugs tethered and running in escort configuration (running stern/transom) outside standard harbor basin: **+30% to +50%** tariff base.
- **Adverse Weather Operations**: Ops conducted between Beaufort 5 and 6 with Harbor Master permit: **+30%** surcharge.
- **Night Navigation (18:00 - 06:00)**: **+30%** surcharge.
- **Dangerous Goods Ship Handling (Class 1, 2, 3)**: **+20% to +30%** towage premium for fire-fighting equipped (FiFi-1 certified) tugs.

## 4. Architectural Fit & Implementation Blueprint
- **Data Schemas**:
  - `DangerousCargoManifest`: IMDG class, UN number, direct-discharge flag (`is_direct_discharge: boolean`), max yard dwell limit hours.
  - `TugAllocationPlan`: Vessel LOA, draft, DWT, wind speed (m/s), current (knots), allocated tugs array with individual BP certified.
- **Validation Rules**:
  - `Class 1 || Class 7 || Class 5.2` -> Reject yard slot allocation; require direct-gate pass dispatch ID.
  - Wind speed >= 12 m/s or Current > 3.0 knots -> Flag weather halt; require emergency override or abort.
  - Tug allocation total BP < matrix threshold -> Reject berthing clearance.
