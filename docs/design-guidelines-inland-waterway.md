# Design Guidelines — Inland Waterway, Feeder Barging & Port Facility Security (Phases 187-190)

## 1. Visual Hierarchy & Color Palette
- **Obsidian Dark Mode**: Base background `#0B0F19`, Card background `#111827`, Border `#1F2937`.
- **Waterway Cyan (`#06B6D4`)**: Used for river channel status, bridge clearance, and inland waterway metrics.
- **Feeder Emerald (`#10B981`)**: Used for barging routes, TEU container throughput, and port fee savings.
- **SAR Amber (`#F59E0B`)**: Used for maritime search & rescue radius, drift vectors, and wreck removal notices.
- **ISPS Security Crimson (`#EF4444` & `#DC2626`)**: Used for ISPS Level 2/3 alerts, Declaration of Security (DoS) requirements, and perimeter lockdown triggers.

## 2. Typography & Spatial System
- Primary Font: `Inter`, `SF Pro Display`, `system-ui`.
- Monospace Data Font: `JetBrains Mono`, `Fira Code` for GPS coordinates, TEU counts, and ISPS DoS IDs.
- Spacing: 8pt grid system with rounded corners (`rounded-xl` / `rounded-2xl`).
