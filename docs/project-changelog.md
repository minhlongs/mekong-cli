# Project Changelog - Mekong CLI v6.0

- **Phase 358/Maritime Cyber Resilience & OT/IT Segmentation:** Shipped `MaritimeCyberEngine` implementing IMO Resolution MSC.428(98) and IACS UR E26/E27, IEC 62443 zone segmentation scoring, IEC 61162 / NMEA 0183 checksum error & GPS position jump anomaly detection, multi-WAN Starlink LEO $\to$ VSAT GEO $\to$ L-Band failover, and unauthorized physical USB bridge breach containment.
- **Architecture & Interfaces:** Built using Hybrid Modular Facade pattern with all files strictly $< 200\text{ LOC}$, 4 Typer CLI command groups with 8 bilingual Vietnamese aliases (`lpgreliq`/`hoalonglpg`, `sludgeburn`/`xulydaucan`, `mooringtension`/`cangdaybuoc`, `maritimecyber`/`anninhmangtau`), 4 FastMCP tools in `scripts/mcp_server.py`, and 18/18 zero-mock tests passing 100%.
