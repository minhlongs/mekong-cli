# Project Changelog - Mekong CLI v6.0

## [2026-10-15] - Invited Pilot Release Candidate (Engine API, Dashboard Demo, CLI Release Gate)
- **Invite-only access:** Tenant creation (`POST /billing/tenants`, `POST /v1/onboard/signup`) requires a single-use `invite_code` when `PILOT_MODE` is on. Only SHA-256 hashes are stored, redemption is atomic with tenant creation, and the API key is shown once. Operators issue up to five codes through `POST/GET /billing/invites` with the service token.
- **Mission execution:** `POST /v1/tasks` still returns a pending mission (201). A D1 `mission_outbox` and the `mekong-mission-queue` producer/consumer now run missions through the PEV orchestrator, LLM-only in pilot mode (`api` and `shell` steps are rejected). Delivery is idempotent, with three retries, the `mekong-mission-dlq` dead-letter queue, and exactly-once debit and refund entries in `mission_credit_events`.
- **Dashboard demo:** `apps/dashboard` deploys to Cloudflare Workers through vinext at `ide.mekongmind.com`. Metrics are labelled synthetic, the hard-coded localhost API target is gone, and dashboard API routes are guarded outside demo mode.
- **Environments and release:** Separate staging D1, KV and queues. Migrations through `0016_pilot_invites_and_mission_outbox.sql` are additive. The canonical `deploy-cf.yml` pipeline verifies and deploys Engine API, Dashboard demo, and MekongMind Pages site through staging before production, then runs health checks, a 30-minute synthetic monitor, and automatic rollback. Legacy deploy workflows remain preserved with `.disabled` extensions. GitHub Release and PyPI publication in `release.yml` depend on `release-checks`. The engine `test` script sets `minForks=1` so vitest 2.x accepts `maxForks=2`.
- **Docs:** Pilot docs no longer claim an SLA, pricing or production readiness. The support runbook defines rollback at an error rate above 5%, latency above twice baseline, or any security alert, with 30 minutes of monitoring after deploy.
- **Verification:** `tests/test_pilot_release_readiness.py` passes 7/7, engine typecheck and 171 vitest tests pass, and dashboard typecheck passes.
