## Làm việc thế nào? Plan → Execute → Verify

Mọi nhiệm vụ đều trải qua PEV loop — Plan, Execute, Verify:

```
Bạn: "Tạo báo cáo tài chính Q2 cho startup của tôi"

[PLAN]
AI phân tích → 4 bước:
1. Thu thập dữ liệu giao dịch
2. Tính toán doanh thu/chi phí
3. Tạo báo cáo theo chuẩn
4. Viết executive summary

[EXECUTE]
4 agents chạy song song:
- GitAgent: lấy data từ CSV
- LLM Agent: phân tích, tính toán
- FileAgent: tạo file Excel
- ContentAgent: viết summary

[VERIFY]
Kiểm tra: số chính xác? định dạng đúng?
Nếu lỗi → tự sửa, chạy lại

[OUTPUT]
Bạn nhận báo cáo hoàn chỉnh trong 5 phút.
Credits: -3
```

Không cần bạn viết prompt phức tạp. Không cần bạn chỉnh sửa code. Chỉ cần nói bằng tiếng Việt.

## Công nghệ: Bạn sở hữu dữ liệu, tự chọn LLM

Mekong IDE không khóa bạn vào một nhà cung cấp.

### Option 1: Chạy local (MIỄN PHÍ)

```bash
# Cài Ollama (1 lệnh)
curl -fsSL https://ollama.ai/install.sh | sh

# Tải model (Qwen 2.5 coder - 4.7GB)
ollama pull qwen2.5-coder

# Cấu hình Mekong IDE
export LLM_BASE_URL=http://localhost:11434/v1
export LLM_MODEL=qwen2.5-coder

# Chạy
mekong cook "Xây dựng MVP cho ý tưởng startup"
```

**Chi phí:** $0. Chỉ tốn điện.

### Option 2: Cloud API (linh hoạt)

```bash
export LLM_BASE_URL=https://openrouter.ai/api/v1
export LLM_API_KEY=sk-or-v1-...
export LLM_MODEL=anthropic/claude-sonnet-4
```

Hỗ trợ: Claude, GPT-4, Qwen, Gemini, DeepSeek, và 50+ model khác.

## Câu hỏi thường gặp (FAQ)

**Q: Tôi không biết code, có dùng được không?**  
A: Có! Mekong IDE viết code giúp bạn. Bạn chỉ cần mô tả bằng tiếng Việt tự nhiên.

**Q: Có cần trả phí hàng tháng không?**  
A: Có, subscription $49/tháng trở lên. Credits dùng hết mua thêm.

**Q: Credits là gì?**  
A: Mỗi lệnh AI tiêu 1-5 credits. Ví dụ: `/cook "Hello World FastAPI"` = 2 credits.

**Q: Dữ liệu của tôi có an toàn không?**  
A: Chạy local → dữ liệu không rời máy. Dùng cloud → mã hóa end-to-end. Không train model trên data của bạn.

**Q: Có hỗ trợ thuế Việt Nam không?**  
A: Có! Lệnh `/thue_dnvn` hỗ trợ thuế TNCN, TNDN, GTGT, hóa đơn TT78. Tính toán theo biểu thuế 2024-2025.

**Q: Có trial miễn phí không?**  
A: 14 ngày trial, hoàn tiền nếu không hài lòng. Không cần thẻ — chuyển khoản VietQR.

**Q: Hỗ trợ LLM nào?**  
A: Claude, GPT-4, Qwen, Gemini, DeepSeek, và bất kỳ OpenAI-compatible API. Miễn phí với Ollama local.

**Q: Có tích hợp Zalo OA không?**  
A: Có. Nhận báo cáo, alert, thông báo qua Zalo OA. Cài đặt 1 lần, hoạt động tự động.

**Q: Tôi cần máy tính mạnh không?**  
A: Chạy cloud — bất kỳ máy nào có trình duyệt. Chạy local — cần 16GB RAM (M1/M2/M3 hoặc Intel i5+).
