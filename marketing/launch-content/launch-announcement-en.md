### How It Works: Plan → Execute → Verify

Every command in Mekong IDE follows the PEV loop:

```
You: "Build a REST API with authentication and deploy to production"

[PLAN]
AI analyzes → creates 4-step plan:
1. Design database schema for users table
2. Implement FastAPI with JWT auth
3. Write integration tests
4. Deploy to Cloudflare Workers

[EXECUTE]
4 agents work in parallel:
- CodeAgent: writes Python/FastAPI
- TestAgent: creates pytest suite  
- GitAgent: commits and branches
- DeployAgent: runs deployment scripts

[VERIFY]
Quality gates check:
- Tests pass? ✓
- Lint passes? ✓
- API responds 200? ✓
- Schema valid? ✓

[OUTPUT]
Deployed API with documentation. Credits: -4 deducted.
```

You describe what you want in natural language. Mekong IDE handles the rest — planning, executing, verifying, and delivering working results.
