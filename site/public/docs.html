/api/v1/swarm/dispatch

speed 120 req/min key Bearer Auth

Deterministic goal dispatch to autonomous multi-agent pipelines. Automatically parses the input prompt, decomposes into sub-agent AST tasks (CEO, CTO, TaxEngine), and provisions a sandboxed SQLite WAL context.

EXECUTION ISOLATION
Ring-3 WASM Sandbox

tune Request Parameters (Body)

Content-Type: application/json
Parameter Type Required Description
goal string Required Plaintext or structured natural-language task definition dispatched across the swarm.
recipe string Optional Recipe manifest identifier (e.g. saigon-dev/tt78-engine). Defaults to auto-detect.
max_mcu float Optional Compute unit circuit-breaker cap. Dispatches abort if quota exceeds threshold. Default: 2.50 MCU.
concurrency integer Optional Max parallel autonomous agent threads spawned in this DAG. Default: 4, Max: 32.
enclave_isolation boolean Optional Execute inside client-side RAM barrier without outbound network telemetry. Default: false.
