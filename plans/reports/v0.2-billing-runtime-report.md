# v0.2 Billing + Runtime Fix Report

**Date:** 2026-08-16
**Status:** COMPLETE

## Summary

Fixed two mismatches in `src/core/mcu_billing.py` and `src/core/runtime_adapter.py`:
1. Added `MCUBilling.check_quota()` (was missing — Protocol required it, impl didn't have it)
2. Converted `MekongCoreRuntimeImpl` from async to sync (all `async def` → `def`, all `await` removed)

## Changes

### src/core/mcu_billing.py
- Added `from src.core.protocols import QuotaStatus` import
- Added `check_quota(self, tenant_id: str) -> QuotaStatus` method after `get_balance()`:
  - Returns `QuotaStatus(remaining_mcu=balance, total_mcu=balance, tier=tier, reset_at=...)`
  - Tier lookup: uses `_get_tier_for_org()` if it exists, falls back to `"basic"`
  - Gracefully handles missing `_get_tier_for_org` or any exception

### src/core/runtime_adapter.py
- All `MekongCoreRuntimeImpl` methods: `async def` → `def` (run, goal, plan, delegate, execute, observe, verify, repair, remember, commit, _run_task_loop)
- Removed all `await` calls; direct sync invocation for dispatcher/tool_registry/telemetry/memory_store/billing
- `commit()` billing path changed:
  - Old: `self._billing.deduct(self._agent_id, "standard")` (async assumption)
  - New: `self._billing.record_usage(self._agent_id, 0, "default", "run")` then `self._billing.check_quota(self._agent_id)` (if available)
- Added local `CheckSpec`, `SideEffect`, `RepairAction` dataclasses (were previously imported from protocols)
- Preserved `MekongCoreRuntime` Protocol as-is (still async — Protocol is a typing surface, not implementation)
