## Database Schema

```sql
CREATE TABLE leads (
  id UUID PRIMARY KEY,
  company_name TEXT NOT NULL,
  contact_name TEXT,
  email TEXT,
  phone TEXT,
  stage TEXT CHECK (stage IN ('new', 'contacted', 'qualified',
                               'proposal', 'negotiation',
                               'closed_won', 'closed_lost')),
  estimated_value INTEGER,
  probability INTEGER DEFAULT 0,
  last_contact_date TEXT,
  next_followup_date TEXT,
  notes TEXT,
  created_at DEFAULT NOW(),
  updated_at DEFAULT NOW()
);

CREATE TABLE activities (
  id UUID PRIMARY KEY,
  lead_id UUID REFERENCES leads(id),
  activity_type TEXT,
  description TEXT,
  created_at DEFAULT NOW()
);

CREATE INDEX idx_leads_stage ON leads(stage);
CREATE INDEX idx_leads_followup ON leads(next_followup_date);
```

## Build & Deploy

### Local Development

```bash
cd apps/crm
npm install
npm run dev
# http://localhost:5174
```

### Production Build

```bash
npm run build
# Output: apps/crm/dist/
```

### Deploy to Cloudflare

```bash
# 1. Create D1 database
npx wrangler d1 create crm-db

# 2. Update wrangler.toml with database_id

# 3. Run migrations
npx wrangler d1 migrations apply crm-db

# 4. Deploy Worker + Pages
npx wrangler deploy
npx wrangler pages deploy dist/
```

**Production URLs:**
- Frontend: `https://crm.mekong-cli.pages.dev`
- API: `https://crm-api.mekong-cli.workers.dev`
