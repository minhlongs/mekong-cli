## How it works

```
mekong run --goal "Analyze monthly revenue"
mekong run --goal "Deploy production" --verbose
```

Wiring in `src/commands/run.py` → `_build_runtime()`:

| Dependency | Source | Notes |
|---|---|---|
| `MemoryStoreBridge` | `src.core.adapters.memory_store_adapter` | YAML+vector memory, implements `MemoryBridge` protocol |
| `MCUBilling` | `src.core.mcu_billing` | SQLite WAL credit store |
| `ToolRegistry` | `src.core.tool_registry` | Dynamic tool discovery + execution |
| `_NullTelemetry` | inline stub | Runtime uses `hasattr` check — gracefully skips if absent |
| `_NullDispatcher` | inline stub | Runtime falls back when `dispatch()` not implemented |

Runtime is instantiated as `MekongCoreRuntimeImpl(agent_id="cli")` and executed via `asyncio.run()`.
