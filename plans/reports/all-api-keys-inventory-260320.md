## ⚠️ Security Notes

1. **Placeholder Credentials**: Many keys use `placeholder`, `dummy`, or `test` values — these are NOT production-ready.

2. **Cloudflare Secrets**: Actual secrets are stored in Cloudflare dashboard, not in `.env` files. Use:
   ```bash
   wrangler secret put <SECRET_NAME>
   ```

3. **Missing Production Keys**:
   - `POLAR_API_KEY` for production (currently only test/placeholder)
   - `POLAR_WEBHOOK_SECRET` for production (currently only placeholder)
   - `STRIPE_SECRET_KEY` for production (currently only test)

4. **Git Safety**: `.env` and `.env.local` files should NEVER be committed. Verify `.gitignore`:
   ```bash
   git check-ignore .env .env.local
   ```
