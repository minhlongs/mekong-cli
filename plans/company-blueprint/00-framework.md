# Step 00 — Master Framework
**Baseline checked:** 2026-10-14
**Stage:** Zero → problem-solution fit (PSF)
**Goal:** $1M ARR within 12 months, an aspiration rather than a forecast
**Evidence note:** The prior framework records zero paying customers and no formal beta. Reconfirm before external use.

## Business
Mekong CLI is an open-source, local-first AI agent runtime for solo companies and solo builders. The current product supports goal planning, agent delegation, execution, verification, repair, memory, and commit; see the repository README and core contract. The initial ICP is a technically capable solo founder or very small team with a recurring business or software workflow. Start with one workflow and one user problem. The possible subscription or usage-based managed offer is a hypothesis; the current repository does not establish pricing, willingness to pay, or repeatable demand.

Keep the following separate:
- Verified: public repository and MIT license; provider-neutral runtime boundaries are documented.
- Planning target: $1M ARR within 12 months.
- Unknown: paying users, retention, CAC, LTV, addressable market, paid conversion, and contribution margin.

## Agentic
One human founder remains accountable. AI roles support discovery, product, engineering, revenue, operations, and governance. Agents may research, draft, classify, and prepare reversible work; humans approve external communications, legal or financial commitments, access to customer data, production changes, and other high-risk actions. Use the canonical lifecycle and repair cap in the runtime contract.

## Governance
Use a source and date for market, legal, and financial claims. No synthetic revenue events, repository size, feature count, or agent count is traction. Reassess stage only when documented user evidence supports it. Vietnam legal pointers and source links are in Step 02.

## Stage gate
Move beyond Zero→PSF only after a defined ICP repeatedly completes the selected workflow and at least some users pay and return. Move toward scale only after retention, cost to serve, and acquisition are measured. Do not treat the 12-month ARR aspiration as a forecast.
