# Step 09 — Website and Landing Narrative

## Business
Structure the page around a single verified workflow:
1. Headline: “A local-first AI agent runtime for repeatable work.”
2. Explain the user problem and current manual/tool workaround.
3. Show one reproducible CLI workflow with inputs, outputs, and limitations.
4. Explain where human approval and verification fit.
5. State install requirements, supported providers, license, and data handling accurately.
6. Offer a low-friction next action: inspect the repository, install, or request a pilot.
7. Add pricing only after an offer and terms are approved.

Do not claim department replacement, customer outcomes, security guarantees, pricing, or product coverage without evidence.

## Agentic
Agents may draft page variants from the approved claims ledger and generate demo scripts. Engineering checks screenshots and commands against the current build. The founder approves the final page.

## Governance
Keep privacy, telemetry, provider processing, and support disclosures visible and accurate. Use only consented testimonials and linked references. Track copy changes and evidence dates.
