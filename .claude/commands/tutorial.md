# /tutorial — Get Started with Mekong CLI

## 5-Step Walkthrough

### Step 1: Set API Keys
Run `/studio-settings` or set environment variables:
```
export OPENAI_API_KEY=sk-...
export ANTHROPIC_API_KEY=sk-...
```

### Step 2: Choose Your Agents
Run `/agents --list` to see available agents:
- CEO, CTO, CMO, CFO, CSO, COO, CHRO
- 31 Department Heads

### Step 3: Run First Workflow
Try: `/cook "analyze my business idea and give me a 6-month plan"`

### Step 4: View Results
Run `/status` to check:
- MCU credit balance
- Active agents
- Pending workflows

### Step 5: Invite (Referral)
Run `/invite friend@email.com` to earn bonus credits.

## Need Help?
- `/help` — full command list
- `/subscribe --tier starter` — upgrade from trial
