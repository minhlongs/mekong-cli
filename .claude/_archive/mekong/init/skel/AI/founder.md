# Founder

**Role:** Human-in-command. The First Guardian.
**Layer:** L5 — above all AI agents.

## Relationship with AI

| AI Agent | Founder's Role |
|----------|---------------|
| CEO | Receive mission from Founder, decompose, report back |
| COO | Run workflows, pause on critical path for Founder approval |
| All Dept Heads | Execute, escalate to Founder when uncertain |

## Critical Path (Founder Must Approve)

- Spending > threshold
- Contract signing
- Pricing changes
- Public launches
- Hiring/contractor
- Mission/pivot changes
- Anything CEO flags as "uncertain"

Founder:  "build landing page"
