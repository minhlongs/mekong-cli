Sơ đồ Topology Mạng

Network Topology Map

Hệ thống kết hợp giữa định tuyến đồng bộ qua API Gateway và giao tiếp bất đồng bộ qua Event Bus Apache Kafka giúp các dịch vụ chạy biệt lập và đạt hiệu năng tối ưu.

A hybrid network layout combining synchronous HTTP Gateway routing with highly resilient asynchronous messaging over Apache Kafka event bus.

  • Nginx API Gateway: Điểm truy cập duy nhất, xử lý định tuyến và bảo mật.
  • Kafka Event Bus: Giao tiếp bất đồng bộ giữa Backend, AI và Blockchain Ledger.
  • CoreDNS Service Discovery: Tự động phân giải địa chỉ giữa các Service.
  • Nginx API Gateway: Central ingress handler with routing and rate-limiting.
  • Kafka Event Bus: Decoupled messaging between Backend, AI, and Blockchain nodes.
  • CoreDNS Service Discovery: Automatic internal host-name resolution.

Sức Chịu Tải 10.000 VUs Đồng Thời

10,000 Concurrent VUs Tested

Chúng tôi sử dụng k6 để mô phỏng tải cực đại của thị trường bất động sản Cần Thơ. Kịch bản test chạy thử nghiệm tăng dần Virtual Users và thiết lập các ranh giới khắt khe về thời gian phản hồi.

Leveraging k6 load test engine to simulate peak search traffic. Scenarios are run to push concurrency levels while maintaining strict response limits.

  • Playwright E2E: Tự động hoá kiểm thử các luồng form đăng ký thực tế trên browser.
  • Chỉ số p95 Latency: Giữ phản hồi của Gateway & Backend dưới 500ms dưới tải cao.
  • Tỷ lệ lỗi tối đa: Thấp hơn 1% trong suốt quá trình test.
  • Playwright E2E: Real browser assertions checking lead submission success states.
  • p95 Performance Target: Gateway responses remain under 500ms at peak load.
  • Acceptable Fail Rate: Strictly limits errors to less than 1% during tests.
